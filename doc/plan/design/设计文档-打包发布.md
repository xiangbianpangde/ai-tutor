# 设计文档：打包发布

> 涉及模块：构建配置、**Nuitka（onedir）**、electron-builder
> 解决问题：#21(独立应用)
> **⚠️ 2026-06-15 修正（C5 波）**：原方案用 **PyInstaller onefile**，被 v3.1 走向决议 R-01
> 证伪——onefile 每次启动解压到临时目录（科学计算栈冷启 8-15s + 杀软高误报）。改 **Nuitka
> onedir**（真编译 C，启动快、误报低、目录形态便于 electron extraResources 引用）。对应实现
> 模块 **M-015 打包调度**（`backend/build/`：BuildOrchestrator / NuitkaBuilder / UPXCompressor /
> ArtifactVerifier）。体积/UPX 为**软约束**（warn only，FDR-M015-002/ADR-009）。

## 背景

当前 AI-Tutor 是 Python 项目，需要用户手动安装 Python 3.12+、配置 .env、通过 Claude Desktop 使用。
重构后需要打包成**双击即用的桌面安装包**，零技术门槛。

## 目标

- Windows：`.exe` 安装包（NSIS 或 MSI）
- macOS：`.dmg` 安装包
- 安装后双击桌面图标启动
- 核心教学功能离线可用（BKT / 拓扑排序 / 遗忘曲线），LLM 功能需用户配 API key
- 自动更新支持（Electron autoUpdater）

## 方案

### 打包架构

```
Python 后端
  │ Nuitka --standalone（onedir，真编译 C）
  ▼
ai-tutor-backend/ 目录（backend.bin/.exe + 所有依赖 .so/.pyd + Python 运行时）
  │                           约 130-160MB（onedir，启动快无解压）
  ▼
Electron app
  │ electron-builder（extraResources 整目录引用）
  ▼
AI-Tutor-Setup-2.0.0.exe      约 200-260MB (含 Chromium + Node + 编译后端目录)
```

### 1. Python 后端打包 (Nuitka onedir，M-015 打包调度)

由 `backend/build/` 的 **BuildOrchestrator** 编排四步 FSM（Nuitka 编译 → UPX 软压缩 →
产物校验 → 完成），命令执行器可注入（CI/测试不必真编译）：

```bash
# NuitkaBuilder 生成的核心命令（onedir / standalone）
python -m nuitka \
    --standalone \                      # onedir：不是 onefile（避免每次解压）
    --output-dir=dist \
    --output-filename=ai-tutor-backend \
    --include-data-dir=data=data \      # 初始空数据库
    --nofollow-import-to=pytest \       # 剔测试依赖
    --assume-yes-for-downloads \
    backend/main.py
```

输出：`dist/main.dist/`（onedir 目录，含 `ai-tutor-backend(.exe)` + 依赖运行时）。
- **UPXCompressor**：对目录内大 .so/.pyd 软压缩；UPX 不可用/失败/超目标体积 → **仅 WARN，不抛**
  （FDR-M015-002）。
- **ArtifactVerifier**：校验可执行存在 + 关键依赖目录在 + 体积在软门禁内（超标 WARN）。

### 2. Electron 打包 (electron-builder)

```json
// package.json
{
  "build": {
    "appId": "com.aitutor.desktop",
    "productName": "AI-Tutor",
    "directories": { "output": "release" },
    "extraResources": [
      { "from": "../dist/main.dist", "to": "backend" }
    ],
    "win": {
      "target": ["nsis"],
      "icon": "assets/icon.ico"
    },
    "mac": {
      "target": ["dmg"],
      "icon": "assets/icon.icns"
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true
    }
  }
}
```

### 3. 启动流程

```
用户双击 AI-Tutor.exe
  │
  ▼
Electron Main Process
  ├── 1. 检查系统资源
  ├── 2. spawn resources/backend/ai-tutor-backend(.exe) (child_process)
  │      ├── 环境变量: AI_TUTOR_HOME = %APPDATA%/AI-Tutor
  │      └── 监听 stdout "Uvicorn running on http://127.0.0.1:18501"
  ├── 3. 轮询 GET /api/knowledge/health (最多等 10s)
  ├── 4. 创建 BrowserWindow → load React app
  │      └── React 连接 http://localhost:18501 + WebSocket
  └── 5. 窗口 on('closed') → kill backend.exe
```

### 4. 数据目录

```
%APPDATA%/AI-Tutor/          (Windows)
~/Library/Application Support/AI-Tutor/  (macOS)
  ├── data/
  │   ├── tutor.db            # SQLite 数据库
  │   ├── settings.json       # 用户设置
  │   └── {user_id}/          # 用户数据文件
  └── logs/
      └── ai-tutor.log
```

## 影响范围

- **新增**：`backend/build/`（M-015 打包调度：orchestrator/nuitka/upx/verifier）、`electron-builder` 配置

- **不修改**：核心业务逻辑

## 风险

| 风险 | 缓解 |
|------|------|
| Nuitka 编译耗时（首次 5-15min） | 一次性成本；CI 缓存 .build 中间产物；onedir 增量重编译快 |
| Nuitka 打包体积（130-160MB） | 软约束（FDR-M015-002）：UPX 软压缩 + NSIS 二次压缩；超标仅 WARN 不阻塞 |
| 杀毒软件误报 | Nuitka 真编译 C，误报远低于 PyInstaller onefile（onefile 自解压是误报主因，R-01）；代码签名证书可选（约 $200/年）|
| macOS 公证（notarization） | Apple Developer 账号 ($99/年) + 公证流程 |
| Python 版本兼容（Windows 7/8） | Python 3.12 最低要求 Windows 10，放弃旧系统 |
| 依赖库（numpy/scipy）打包后在某些机器上崩溃 | CI 矩阵测试 Win10/Win11/macOS 14+ |
| 自动更新增量包过大 | electron-updater 支持差分更新 (delta)，仅下发变更 |
