# 设计文档：打包发布

> 涉及模块：构建配置、PyInstaller、electron-builder
> 解决问题：#21(独立应用)

## 背景

当前 AI-Tutor 是 Python 项目，需要用户手动安装 Python 3.12+、配置 .env、通过 Claude Desktop 使用。
重构后需要打包成**双击即用的桌面安装包**，零技术门槛。

## 目标

- Windows：`.exe` 安装包（NSIS 或 MSI）
- macOS：`.dmg` 安装包
- 安装后双击桌面图标启动
- 核心教学功能离线可用（BKT / 拓扑排序 / 遗忘曲线），LLM 功能需用户配 API key
- 自动更新支持（Electron autoUpdater）

## 方案

### 打包架构

```
Python 后端
  │ PyInstaller
  ▼
backend.exe (Python 3.12 embedded + 所有依赖 + FastAPI app)
  │                           约 120-150MB
  ▼
Electron app
  │ electron-builder
  ▼
AI-Tutor-Setup-2.0.0.exe      约 200-250MB (含 Chromium + Node + Python embedded)
```

### 1. Python 后端打包 (PyInstaller)

```
# pyinstaller.spec
a = Analysis(
    ['backend/main.py'],
    pathex=[],
    binaries=[],
    datas=[
        ('backend/core/models.py', 'core'),   # SQLAlchemy models
        ('data/', 'data'),                     # 初始空数据库
    ],
    hiddenimports=[
        'sqlalchemy', 'numpy', 'scipy', 'networkx',
        'pydantic', 'fastapi', 'uvicorn',
        'openai', 'pypinyin', 'structlog',
    ],
    ...
)
pyz = PYZ(a.pure)
exe = EXE(pyz, a.scripts, ..., name='ai-tutor-backend', console=False)
```

输出：`dist/ai-tutor-backend.exe`（单文件，无控制台窗口）

### 2. Electron 打包 (electron-builder)

```json
// package.json
{
  "build": {
    "appId": "com.aitutor.desktop",
    "productName": "AI-Tutor",
    "directories": { "output": "release" },
    "extraResources": [
      { "from": "../dist/ai-tutor-backend.exe", "to": "backend/ai-tutor-backend.exe" }
    ],
    "win": {
      "target": ["nsis"],
      "icon": "assets/icon.ico"
    },
    "mac": {
      "target": ["dmg"],
      "icon": "assets/icon.icns"
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true
    }
  }
}
```

### 3. 启动流程

```
用户双击 AI-Tutor.exe
  │
  ▼
Electron Main Process
  ├── 1. 检查系统资源
  ├── 2. spawn backend.exe (child_process)
  │      ├── 环境变量: AI_TUTOR_HOME = %APPDATA%/AI-Tutor
  │      └── 监听 stdout "Uvicorn running on http://127.0.0.1:18501"
  ├── 3. 轮询 GET /api/knowledge/health (最多等 10s)
  ├── 4. 创建 BrowserWindow → load React app
  │      └── React 连接 http://localhost:18501 + WebSocket
  └── 5. 窗口 on('closed') → kill backend.exe
```

### 4. 数据目录

```
%APPDATA%/AI-Tutor/          (Windows)
~/Library/Application Support/AI-Tutor/  (macOS)
  ├── data/
  │   ├── tutor.db            # SQLite 数据库
  │   ├── settings.json       # 用户设置
  │   └── {user_id}/          # 用户数据文件
  └── logs/
      └── ai-tutor.log
```

## 影响范围

- **新增**：`pyinstaller.spec`、`electron-builder` 配置
- **新增**：`assets/`（图标）
- **修改**：`backend/main.py`（加 health endpoint 用于启动检测）
- **不修改**：核心业务逻辑

## 风险

| 风险 | 缓解 |
|------|------|
| PyInstaller 打包体积大（150MB+） | 正常。Python 科学计算栈 + 依赖无法更小。NSIS 压缩后可到 100MB |
| 杀毒软件误报 PyInstaller exe | 代码签名证书（可选，约 $200/年）|
| macOS 公证（notarization） | Apple Developer 账号 ($99/年) + 公证流程 |
| Python 版本兼容（Windows 7/8） | Python 3.12 最低要求 Windows 10，放弃旧系统 |
| 依赖库（numpy/scipy）打包后在某些机器上崩溃 | CI 矩阵测试 Win10/Win11/macOS 14+ |
| 自动更新增量包过大 | electron-updater 支持差分更新 (delta)，仅下发变更 |
