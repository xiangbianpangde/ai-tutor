# 设计文档：前端桌面应用

> 涉及模块：`frontend/`（Electron + React + Vite）

## 背景

当前 AI-Tutor 仅有简陋的 dashboard HTML 页面（`servers/dashboard/templates/index.html`），
用户通过 Claude Desktop 文本界面交互。需要构建一个完整的桌面 GUI，让用户直接操作。

## 目标

- Electron 桌面应用，支持 Windows / macOS
- 5 个核心页面：仪表盘、知识库管理、学习中心、复习中心、设置
- 知识图谱力导向图、遗忘曲线、掌握度热力图等可视化
- WebSocket 实时通信，教学反馈无延迟
- 符合开发规范：组件化、TypeScript、测试覆盖

## 方案

### 技术栈

| 层 | 技术 | 原因 |
|----|------|------|
| 桌面壳 | Electron 33+ | 跨平台、成熟生态、文件系统访问 |
| 前端框架 | React 19 + TypeScript | 生态丰富、ECharts/D3 集成好 |
| 构建 | Vite 6 | 快、Electron 插件成熟 |
| 可视化 | ECharts 5 + D3.js | ECharts 做统计图，D3 做力导向 KG 图 |
| UI 组件 | Ant Design 5 | 中文友好、表格/表单/布局丰富 |
| 状态管理 | Zustand | 轻量、适合单用户桌面应用 |
| HTTP | axios | 成熟稳定 |
| WebSocket | native WebSocket | 浏览器原生，零依赖 |

### 页面设计

#### 1. 仪表盘 (Dashboard)

```
┌──────────────────────────────────────────────┐
│  📊 学习概览                          [设置]  │
├──────────┬──────────┬──────────┬─────────────┤
│ 已掌握   │ 学习中   │ 今日学习 │ 连续天数    │
│  17/30   │   8      │  45 min  │  5 天       │
├──────────┴──────────┴──────────┴─────────────┤
│  📈 遗忘曲线            │  🧠 认知负荷       │
│  (ECharts 折线图)       │  (仪表盘)          │
│                          │                    │
├──────────────────────────┼───────────────────┤
│  🗺️ 知识图谱 (D3 力导向) │ 📋 今日推荐复习   │
│  (可拖拽/缩放/点击)      │ 1. 导数定义        │
│                          │ 2. 链式法则        │
│                          │ 3. 极限计算        │
└──────────────────────────┴───────────────────┘
```

#### 2. 知识库管理 (KnowledgeBase)

- 左侧：科目列表（树形）
- 右侧：知识图谱可视化（D3 力导向图）
  - 节点 = 概念，按掌握度着色（绿=已掌握 / 黄=学习中 / 灰=未学）
  - 边 = 前置关系，箭头方向
  - 点击节点弹出概念卡片（定义/例子/误解/置信度）
- 底部：操作栏（导入资料 / 构建图谱 / 审查图谱）

#### 3. 学习中心 (LearningCenter)

- 顶部：进度条（Phase N/M，概念 X/Y）
- 中央：教学区域
  - 讲解卡片 / 提问卡片 / 练习卡片
  - 输入框 → 提交答案 → 即时反馈
  - 打断按钮（"我不理解" / "太简单了" / "举个例"）
- 右侧：状态面板（当前策略 / 心流等级 / 认知负荷）
- 底部：番茄钟计时器 + 休息提醒

#### 4. 复习中心 (ReviewCenter)

- 每日复习计划列表（按优先级排序）
- 复习模式标签（测验 / 概念图 / 自讲 / 错题回顾）
- 遗忘曲线展示
- 复习日历热力图（类似 GitHub contribution）

#### 5. 设置 (Settings)

- LLM API 配置（provider / key / model / 预算上限）
- 学习偏好（pace / 每日目标时长 / 番茄钟间隔）
- 数据管理（导出/导入/清空）
- 外观（主题 / 字体大小）
- 关于（版本号 / 依赖许可）

## 影响范围

- **新增**：`frontend/` 整个目录
- **新增依赖**：electron, react, vite, echarts, d3, antd, zustand, axios
- **删除**：`servers/dashboard/`（被前端 dashboard 页面替代）
- **不修改**：`backend/` API 层（前端仅消费 API）

## 风险

| 风险 | 缓解 |
|------|------|
| D3 力导向图性能（200+ 概念） | 虚拟化 + 分级渲染：默认显示 2 跳邻域，按需展开 |
| Electron 启动慢（Python 后端冷启动） | splash screen + 健康检查轮询 |
| 跨平台兼容（Windows/macOS 文件路径） | Electron 提供统一 path API |
| 前后端通信安全 | 本地 localhost，不暴露外网；CORS 仅允许 localhost |
