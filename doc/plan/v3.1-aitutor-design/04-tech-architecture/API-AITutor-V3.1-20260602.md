# 接口技术规范 — AITutor V3.1

> 8 个核心 IF 全部映射为 API 技术规范。来源：[TD:IF-001~008]

---

## API-001 服务启动（IF-001）

- **关联契约**：IF-001
- **协议类型**：进程内函数调用（`app: FastAPI`）
- **序列化格式**：Python 对象（pyproject.toml → dict）
- **认证方式**：无（启动期）
- **限流策略**：无（启动期）
- **版本策略**：无（启动期）
- **兼容性矩阵**：N/A（启动期无版本）
- **错误处理**：
  - E00101 依赖缺失 → 拒绝启动 + 详细日志
  - E00102 端口冲突 → 提示用户改端口
  - E00103 旧库不兼容 → 自动迁移 v1→v2 / 失败备份
  - E00106 MW 初始化失败 → 退出码非 0
- **性能要求**：启动 ≤30s（含 5MW 装配）
- **来源标注**：[TD:IF-001] + [TD:DE-001~004]

## API-002 学习回合（IF-002）

- **关联契约**：IF-002
- **协议类型**：REST（HTTP POST /api/v1/session/{session_id}/turn）
- **序列化格式**：JSON（pydantic v2）
- **认证方式**：Depends(auth) Bearer Token
- **限流策略**：100 QPS / 用户 + 10 并发回合
- **版本策略**：URL 路径版本（/api/v1/）
- **兼容性矩阵**：
  | 版本 | v1.0 | v1.1（V3.2）| v2.0（V4.0）|
  |------|------|-----------|-----------|
  | v1.0 | -   | 向后兼容 | 不兼容 |
  | v1.1 | 兼容 | -   | 需适配层 |
  | 升级路径 | 自动 | 需双写过渡期 |
- **错误处理**：
  - E00901 LLM 评分失败 → 走 FSM 兜底 10%
  - E00902 FSM 卡死 → LLM 兜底 + audit_log
  - E00903 FSRS 版本低 → 升级提示
- **性能要求**：单回合 ≤5s（P95）
- **来源标注**：[TD:IF-002] + [TD:DE-009/019]

## API-003 RAG 检索（IF-003）

- **关联契约**：IF-003
- **协议类型**：进程内 async 协程（`async def retrieve(query, ...)`）
- **序列化格式**：Python TypedDict
- **认证方式**：进程内调用（不暴露外部）
- **限流策略**：单次 ≤10s，超时降级
- **版本策略**：接口内部版本（AGENT_VERSION）
- **兼容性矩阵**：
  | 版本 | v1.0 | v1.1（V3.2 NLI 独立）| v2.0（V4.5 智能路由）|
  |------|------|------------------|------------------|
  | v1.0 | -   | 向后兼容 | 路由字段新增 |
  | v1.1 | 兼容 | -   | 路由字段新增 |
  | 升级路径 | 自动 | 自动（路由字段可选）|
- **错误处理**：
  - E00801 重检索 3 轮仍 < 0.7 → 强制标"无法确认" + 切 web 搜索
  - E00802 NLI 不可用 → 降级 LLM 法官
  - E00803 重路由 → 重试 1 次 / 仍失败走兜底
- **性能要求**：单次 ≤10s（P95）
- **来源标注**：[TD:IF-003] + [TD:ADR-006] + [调研报告:RI-009]

## API-004 数据入库（IF-004）

- **关联契约**：IF-004
- **协议类型**：REST（HTTP POST /api/v1/ingest）
- **序列化格式**：multipart/form-data（PDF）/ JSON（chunk_text）
- **认证方式**：Depends(auth) Bearer Token
- **限流策略**：5 QPS / 用户（PDF 翻译耗资源）
- **版本策略**：URL 路径版本
- **兼容性矩阵**：
  | 版本 | v1.0 | v1.1（V4.0 多用户）|
  |------|------|------------------|
  | v1.0 | -   | user_id 必填 |
  | v1.1 | 兼容 | - |
  | 升级路径 | 自动（user_id 可选）|
- **错误处理**：
  - E01401 pdf2zh 失败 → pdfplumber → LM Studio 3 次降级
  - E01402 LLM 超时 → 重试 1 次
  - E01403 clean 后重复率仍 >30% → 增强 clean + WARN（不阻塞）
- **性能要求**：10 页 PDF ≤60s（P95）
- **来源标注**：[TD:IF-004] + [调研报告:RI-006/PDF-47]

## API-005 打包构建（IF-005）

- **关联契约**：IF-005
- **协议类型**：CI 触发（GitHub Actions workflow_dispatch）
- **序列化格式**：YAML（GitHub Actions）+ JSON（artifacts metadata）
- **认证方式**：GitHub Secrets（GH_TOKEN）
- **限流策略**：CI 配额（GitHub 限制）
- **版本策略**：artifact 标签 + sha256
- **兼容性矩阵**：
  | 版本 | v1.0 | v1.1（V3.5 GUI 形态）|
  |------|------|------------------|
  | v1.0 | -   | 平台字段新增 |
  | v1.1 | 兼容 | - |
  | 升级路径 | 自动（platform 字段可选）|
- **错误处理**：
  - E01501 体积超目标 → UPX 压缩 + 标 ⚠️（warn only，ADR-009 软约束）
  - E01502 工具链不兼容 → 锁版本回退
- **性能要求**：单平台 ≤10min
- **来源标注**：[TD:IF-005] + [TD:ADR-009] + [调研报告:RI-003]

## API-006 红线检测（IF-006）

- **关联契约**：IF-006
- **协议类型**：CI 进程（subprocess）/ pre-commit hook（本地）
- **序列化格式**：JSON（tool output）+ GitHub Actions annotations
- **认证方式**：无（CI 内部）
- **限流策略**：CI 配额
- **版本策略**：tool_version_lock 强约束
- **兼容性矩阵**：
  | 工具 | v0.7.x（Ruff）| v1.0.x（Ruff 升级）|
  |------|------------|----------------|
  | 0.7.x | -        | 不兼容（API 变）|
  | 1.0.x | 不兼容 | - |
  | 升级路径 | TDD 渐进式 |
- **错误处理**：
  - E01601 退出码非 0 → CI 红 + 修复手册链接
  - E01602 合约违反 → Import Linter 报告
  - E01603 覆盖率不达标 → CI 阻断
- **性能要求**：4 工具并行 ≤5min
- **来源标注**：[TD:IF-006] + [TD:ADR-010] + [调研报告:RI-004]

## API-007 长期记忆（IF-007）

- **关联契约**：IF-007
- **协议类型**：进程内 async 协程 + SQLite 事务
- **序列化格式**：JSONB（SQLite JSON1 扩展）
- **认证方式**：进程内（user_id 强校验防 CE-003 串号）
- **限流策略**：1000 QPS / 用户
- **版本策略**：schema 版本（DE-031/032 migration 编号）
- **兼容性矩阵**：
  | 版本 | v1.0 | v1.1（V4.5 重要性评分）|
  |------|------|------------------|
  | v1.0 | -   | importance 字段新增 |
  | v1.1 | 兼容 | - |
  | 升级路径 | 自动（importance 字段可选）|
- **错误处理**：
  - E01301 LLM 提取失败 → 重试 1 次 / 失败丢弃
  - E01302 LRU 淘汰触发 → 淘汰最旧 10%
- **性能要求**：单写 ≤100ms
- **来源标注**：[TD:IF-007] + [TD:ADR-012] + [TD:SR-007]

## API-008 WS 推送（IF-008）

- **关联契约**：IF-008
- **协议类型**：WebSocket（starlette.websockets）
- **序列化格式**：JSON Event（`{event_type, payload, ts, trace_id}`）
- **认证方式**：连接时 Token 校验（subprotocol 协商）
- **限流策略**：max_connections=1000 / 超限 E00202
- **版本策略**：subprotocol 版本（`aitutor.v1`）
- **兼容性矩阵**：
  | subprotocol | v1.0 | v1.1（V3.2 看板聚合）|
  |------------|------|------------------|
  | v1.0 | -   | event_type 新增 |
  | v1.1 | 向后兼容 | - |
  | 升级路径 | 自动（忽略未知 event_type）|
- **错误处理**：
  - E00201 连接断开 → 指数退避 ≤30s + 状态补发
  - E00202 超限拒绝 → 客户端降级轮询
- **性能要求**：端到端 ≤1s（P95）
- **来源标注**：[TD:IF-008] + [TD:B-007] + [TD:SR-008]
