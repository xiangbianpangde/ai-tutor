## TD-001 sqlite-vec 0.1.x API 稳定性

- **债务描述**：TS-006 sqlite-vec 仍在 0.1.x 早期版本，可能存在 API 破坏性变更
- **影响模块**：M-005（向量检索）、M-006（实体记忆）
- **风险等级**：中
- **产生原因**：sqlite-vec 是较新的嵌入式向量扩展，pre-stable
- **偿还计划**：
  - V-1 阶段（3-6 月）评估升级到 0.2.x 或切换 ChromaDB
  - 封装 VectorIndex 抽象层（[AR洞察-007]）
- **接受理由**：当前 0.1.3+ 满足功能需求；单用户场景下风险可控
- **来源标注**：[AR推断:版本号 0.1.3+] + [AR洞察-004/007]

## TD-002 pdf2zh AGPL 法务风险

- **债务描述**：TS-017 pdf2zh 采用 AGPL 协议，商业发布需法务评审
- **影响模块**：M-004（数据管线）、M-007（集成适配器）
- **风险等级**：中
- **产生原因**：pdf2zh 协议选择（[调研报告:RI-006]）
- **偿还计划**：
  - V-1 阶段：法务评审 AGPL 商用细则
  - 备选：切换至 PyMuPDF + 自研翻译（增加开发量）
- **接受理由**：本期为内部工具/单用户；AGPL 仅在网络服务分发时触发
- **来源标注**：[调研报告:RI-006/S-009] + [R-11]

## TD-003 同步调用替代异步（M-002 教学引擎评分）

- **接受理由**：单用户并发低；同步调用简化错误处理
- **来源标注**：[AR推断:单用户场景评估]

## TD-004 FSRS + BKT/DKT 联合追踪未实现

- **债务描述**：M-002 当前仅用 py-fsrs 间隔重复，调研报告 RI-NEW-2 提出的 FSRS + BKT/DKT 联合追踪未实现
- **影响模块**：M-002（教学引擎）
- **风险等级**：轻
- **产生原因**：RA-001 移交 SA-001 阶段的待验证项（[调研报告:RI-NEW-2]）
- **偿还计划**：

- **来源标注**：[调研报告:RI-NEW-2]
