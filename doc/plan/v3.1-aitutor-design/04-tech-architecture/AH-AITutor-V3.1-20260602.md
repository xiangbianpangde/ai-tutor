## AR 洞察（4 条，本轮注入）

### INSIGHT-AR-001 NLI 资源抢占风险
**类型**：性能瓶颈预判
**描述**：AG-008 NLI 模型加载（1.5GB）若与 AG-014 PDF 翻译（512MB）在同一 CPU 池中并发，单机 CPU 4 核下可能争抢
**缓解**：M-001 启动期绑定 NLI 到固定 CPU 亲和性（CPU 0），PDF 翻译走 ThreadPool 走 CPU 1-3
**状态**：已记录到 AC-AITutor-V3.1

### INSIGHT-AR-002 M-016 治理工具链依赖外网
**类型**：部署复杂度
**描述**：pre-commit hooks 拉取远端配置时若断网会失败
**缓解**：本地缓存 `.pre-commit-cache/` + CI 加 `--no-network` 模式
**状态**：已记录到 DP-AITutor-V3.1

### INSIGHT-AR-003 M-013 长期记忆 LRU 淘汰与用户期望冲突
**类型**：技术债务预警
**描述**：M-013 LRU 淘汰最旧 10% 可能误删重要事实
**缓解**：V4.5 引入重要性评分
**状态**：已记录到 TD-AR-006

### INSIGHT-AR-004 ChromaDB 嵌入式 V4.0 风险
**类型**：扩展瓶颈
**描述**：单用户量级 OK，V4.0 多用户后单实例难支撑
**缓解**：V4.0 评估 Qdrant 集群方案
**状态**：已记录到 TD-AR-001
