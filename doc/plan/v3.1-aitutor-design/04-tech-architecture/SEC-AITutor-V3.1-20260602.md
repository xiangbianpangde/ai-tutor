# 安全设计方案 — AITutor V3.1

> 15 个边界全部有安全策略（[TD:BD-AITutor] 100% 达成）。灵魂 4.14 安全左移 9 项全部检查。

---

## SEC-001 用户输入边界（CLI）

- **关联边界**：B-001
- **威胁模型**：CLI 注入 / 路径穿越 / 权限越界
- **认证策略**：API token（CLI 配置文件）
- **授权策略**：用户级单租户，无多用户权限
- **加密策略**：本地存储（无网络传输）
- **审计策略**：CLI 命令日志（结构化）
- **防护措施**：
  - argparse 类型校验
  - 路径白名单（仅 ~/.<app>/ 目录）
  - 拒绝 root 运行（POSIX）
- **合规要求**：无（本地工具）
- **来源标注**：[TD:B-001] + [TD:BR-036] + [灵魂 4.14 输入校验]

## SEC-002 用户输入边界（Web）

- **关联边界**：B-002
- **威胁模型**：XSS / CSRF / 越权 / 会话劫持
- **认证策略**：Depends(auth) Bearer Token（强校验，CE-018 修复）
- **授权策略**：单用户级权限
- **加密策略**：HTTPS（生产）/ HTTP（loopback 开发）
- **审计策略**：所有 HTTP 请求埋点
- **防护措施**：
  - CSP 头（script-src 'self'）
  - CORS 限制（仅 loopback）
  - Cookie HttpOnly + SameSite=Strict
  - Depends(auth) 强校验
  - fingerprint 校验（DE-040）
- **合规要求**：无
- **来源标注**：[TD:B-002] + [TD:CE-018] + [灵魂 4.14 认证覆盖]

## SEC-003 LLM Provider 接口边界

- **关联边界**：B-003
- **威胁模型**：API key 泄露 / 注入攻击（提示词注入）/ 数据外泄
- **认证策略**：API key 环境变量（不入代码 / 不入配置仓库）
- **授权策略**：Provider 侧权限（用户自行管理）
- **加密策略**：HTTPS 1.3（传输）
- **审计策略**：所有 LLM 调用 trace_id + payload 摘要
- **防护措施**：
  - httpx 超时 30s
  - payload 大小限制（10MB）
  - 提示词注入检测（[调研报告:RI-009]）
  - 响应内容脱敏（API key / token 模式）
- **合规要求**：OpenAI TOS / Anthropic TOS 合规
- **来源标注**：[TD:B-003] + [TD:BR-001] + [灵魂 4.14 输入校验]

## SEC-004 NLI 本地推理边界

- **关联边界**：B-004
- **威胁模型**：模型文件篡改 / 推理结果污染
- **认证策略**：loopback（无网络）
- **授权策略**：进程内访问
- **加密策略**：模型文件 sha256 校验
- **审计策略**：推理调用埋点
- **防护措施**：
  - 进程内调用（不开 socket）
  - 模型文件路径白名单
- **合规要求**：模型许可证（CC-BY-SA 等）
- **来源标注**：[TD:B-004] + [TD:EX-015] + [调研报告:RI-009]

## SEC-005 本地资料库边界

- **关联边界**：B-005
- **威胁模型**：路径穿越 / 恶意文件 / 文件大小炸弹
- **认证策略**：用户主动选择目录（GUI 向导）
- **授权策略**：OS 文件权限继承
- **加密策略**：无（用户自有数据）
- **审计策略**：文件扫描日志
- **防护措施**：
  - 路径白名单（仅允许选择的目录）
  - 文件大小限制（PDF ≤ 100MB）
  - 文件类型白名单（PDF / Markdown / 图片）
  - pdf2zh 沙箱（subprocess + 资源限制）
- **合规要求**：无
- **来源标注**：[TD:B-005] + [TD:BP-009/017/018]

## SEC-006 CI / 工具链边界

- **关联边界**：B-006
- **威胁模型**：PR 注入 / 工具链版本破坏 / Secrets 泄露
- **认证策略**：GitHub Secrets 加密
- **授权策略**：CI 权限最小化（仅 PR 读写）
- **加密策略**：GitHub Secrets 加密 + 环境变量
- **审计策略**：CI run 日志（DE-047）
- **防护措施**：
  - 4 工具链锁版本（DE-048）
  - branch protection 阻断
  - pre-commit 本地先跑
  - 修复手册链接
- **合规要求**：NFR-8 6+1 规范
- **来源标注**：[TD:B-006] + [TD:BR-046] + [TD:ADR-010] + [调研报告:RI-004]

## SEC-007 WebSocket 推送输出边界

- **关联边界**：B-007
- **威胁模型**：连接风暴 / 数据劫持 / 拒绝服务
- **认证策略**：连接时 Token 校验
- **授权策略**：user_id 强绑定
- **加密策略**：WSS（生产）/ WS（loopback）
- **审计策略**：连接建立/断开埋点
- **防护措施**：
  - max_connections=1000
  - 指数退避 ≤30s
  - 心跳 5s
  - 状态补发（30s 内）
- **合规要求**：BR-007
- **来源标注**：[TD:B-007] + [TD:BR-007] + [TD:CE-016] + [灵魂 4.14 限流]

## SEC-008 打包产物输出边界

- **关联边界**：B-008
- **威胁模型**：产物篡改 / 供应链攻击
- **认证策略**：CI 签名（GitHub 签名）
- **授权策略**：仅 CI 推送
- **加密策略**：sha256 校验
- **审计策略**：CI build log
- **防护措施**：
  - sha256 强校验
  - 体积门禁（warn only）
  - 三平台矩阵
- **合规要求**：NFR-8
- **来源标注**：[TD:B-008] + [TD:BR-031~033] + [调研报告:RI-003]

## SEC-009 学习结果输出边界

- **关联边界**：B-009
- **威胁模型**：数据越权 / 串号（CE-003）
- **认证策略**：Depends(auth) + user_id 绑定
- **授权策略**：仅本人可看
- **加密策略**：传输 HTTPS
- **审计策略**：所有读操作埋点
- **防护措施**：
  - user_id 强校验（防 CE-003 串号）
  - 数据隔离（按 user_id 分区）
- **合规要求**：无
- **来源标注**：[TD:B-009] + [TD:CE-003] + [灵魂 4.14 最小权限]

## SEC-010 监控指标输出边界

- **关联边界**：B-010
- **威胁模型**：敏感数据泄露（API key / 用户数据）
- **认证策略**：loopback（无外网）
- **授权策略**：Prometheus scrape 仅读
- **加密策略**：脱敏（[TD:BR-038]）
- **审计策略**：Prom 拉取日志
- **防护措施**：
  - structlog JSON 脱敏（API key 模式 → `***`）
  - OTel payload 摘要（不全量传）
  - Prom bind loopback
- **合规要求**：GDPR（脱敏）
- **来源标注**：[TD:B-010] + [TD:BR-004/038] + [TD:EX-007] + [灵魂 4.14 审计日志]

## SEC-011 红线报告输出边界

- **关联边界**：B-011
- **威胁模型**：报告注入 / 修复手册钓鱼
- **认证策略**：CI 内部（无对外）
- **授权策略**：仅 CI artifact
- **加密策略**：无（公开报告）
- **审计策略**：DE-046 redline_report

  - 报告内容转义（防 XSS）
- **合规要求**：NFR-8
- **来源标注**：[TD:B-011] + [TD:BR-050] + [TD:DE-046]

## 密钥管理清单

| 密钥类型 | 存储位置 | 访问控制 |
|---------|---------|---------|
| LLM API Key | 环境变量 / .env | 用户级 |
| WS Token | SQLite（加密）| 进程内 |
| GitHub Token | GitHub Secrets | CI 级 |
| NLI 模型 | 本地文件 | 用户级 |
| 数据库密码 | 无（单用户本地）| OS 权限 |
| session token | JWT + 签名 | 服务端签发 |
