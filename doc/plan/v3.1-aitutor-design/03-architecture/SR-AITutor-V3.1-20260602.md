# 结构风险清单 — AITutor V3.1

> 接收：CE-001~CE-018 / EX-001~EX-033
> 风险数：12（高 5 / 中 4 / 低 3）

---

## SR-001 M-008 模块内聚度偏低
- 描述：M-008 (RAG 引擎) 内含 RAG 路由/NLI/本地索引/翻译 4 种子能力，3/6 项内聚度检查未通过
- 影响模块：M-008, M-010, M-014
- 影响范围：变更时易产生跨子能力副作用
- 缓解策略：V3.2 阶段拆为 4 个子模块（清晰接口边界）；当前通过子能力命名空间隔离
- 监控指标：M-008 接口契约破坏次数 / 月
- 来源：[TD推断:依据=灵魂 4.7 检查] + [SA:CE-006]

## SR-002 M-016 横切治理内聚度中等
- 描述：M-016 同时承担红线编排 + Redline 闸门 + Error Hub 3 职责，4/6 项
- 影响模块：M-016, M-023
- 影响范围：横切关注点扩散
- 缓解策略：当前合并不破坏 D2（横切完整性优先），V3.2 拆分
- 监控指标：M-016 单元测试覆盖率
- 来源：[TD推断:依据=灵魂 4.7 检查]

## SR-003 打包体积与覆盖率冲突
- 描述：CE-011 跨流程风险——补测试 → 体积增 → 触发 EX-023
- 影响模块：M-015, M-016
- 影响范围：GUI 产物阻塞
- 缓解策略：BR-032 改 warn only + 优先 UPX 压缩 + 体积门禁走次级 pipeline
- 监控指标：CLI/GUI 体积 + 覆盖率
- 来源：[SA:CE-011]

## SR-004 红线工具链版本破坏
- 描述：Ruff/Redocly/Import Linter 1.0 前破坏性变更阻塞所有 PR
- 影响模块：M-016, M-020
- 影响范围：开发效率归零
- 缓解策略：DE-048 锁版本 + 升级走 TDD 渐进式
- 监控指标：4 工具版本变更告警
- 来源：[SA:EX-033] + [SA:CE-012]

## SR-005 NLI 部署成本不可控
- 描述：NLI 模型加载/推理慢，可能拖垮 LLM 响应
- 影响模块：M-008 (M-013 NLI 子能力)
- 影响范围：单次查询 ≤ 10s 难达成
- 缓解策略：NLI 异步化 + 缓存 + LLM 法官兜底
- 监控指标：NLI 推理 p99 + LLM 兜底占比
- 来源：[SA:CE-006] + [SA:RI-NEW-1 移交]

## SR-006 复杂度路由阈值未实测
- 描述：BR-020 默认实现（关键字匹配）→ 复杂查询误判为简单
- 影响模块：M-008
- 影响范围：RAG 质量下降
- 缓解策略：V4.5 POC 落地 + 监控 fallback_rate
- 监控指标：fallback_rate / NLI score
- 来源：[SA:CE-010] + [SA:AR-016]

## SR-007 长期记忆数据孤岛复发
- 描述：DE-032 在 BR-028 定义但无专门 BP 负责
- 影响模块：M-013
- 影响范围：长期记忆实际为空
- 缓解策略：BP-013 步骤 3 显式化为"关键事实提取"子流程 + 监控埋点
- 监控指标：long_term_memory 行数 / 日
- 来源：[SA:CE-007] + [SA:AR-017]

## SR-008 WebSocket 连接风暴
- 描述：CE-016 网络抖动 → 多客户端同时重连 → 服务端资源耗尽
- 影响模块：M-002
- 影响范围：服务端崩溃
- 缓解策略：DE-005 max_connections=1000 + 超限拒绝 + 指数退避
- 监控指标：活跃连接数 + 重连率
- 来源：[SA:CE-016] + [SA:EX-020]

## SR-009 文件结构治理弱约束

- 监控指标：file_tree 偏差数
- 来源：[SA:EX-024]

## SR-010 单进程承载压力
- 描述：BR-002 单进程 + 5 类中间件 + 8 编排器 → CPU/IO 压力集中

- 影响范围：性能瓶颈
- 缓解策略：asyncio + ThreadPool + 关键路径 LRU 缓存
- 监控指标：CPU 使用率 / p99 响应
- 来源：[SA:BR-002] + [SA:CE-001 旧库不兼容]

## SR-011 LLM 兜底审计盲区
- 描述：BR-009/010 已定，但 audit_log 表无强制非空约束

- 来源：[SA:CE-008]
