# 架构决策记录 (ADR) — AITutor V2.0

## ADR-001 选择分层架构（主方案）
- **状态**：已接受
- **内容**：采用 6 层分层架构（L1 基础设施→L6 表现层）作为主架构
- **理由**：① 单用户单进程场景下分层架构简单性最优；② 10 模块/20 功能=0.5 落在简洁度最佳区间；③ 与 5 类中间件强制装配（[BR-003]）天然契合
- **拒绝的替代方案**：微服务架构（多进程 gRPC + 消息队列）— 引入不必要的复杂度
- **影响范围**：M-001~M-010 全部模块 + IF-001~IF-030 接口
- **来源标注**：[TD推断 - 4.8 模式决策树匹配]

## ADR-002 GUI 形态保留 3 套适配器接口
- **状态**：已接受（待 PM 决策收敛）
- **内容**：在 M-001 启动层 + M-010 扩展层同时支持 Electron / Tauri / PyWebView 三套打包路径
- **理由**：① OC-1 决策延迟；② 关键路径 POC 未完成；③ 保留 3 套接口成本 < 决策错误返工成本
- **拒绝的替代方案**：默认选 Electron — 体积大、内存高，违背 NFR
- **影响范围**：M-001 启动层、M-010 扩展层、CI/CD 矩阵
- **来源标注**：[SA:AR-001] + [SA:CR-001]

## ADR-003 抗幻觉采用 HaluGate 三级级联
- **状态**：已接受
- **内容**：NLI（~40% 流量）→ SLM（~55%）→ LLM 法官（~5% ≥2 独立打分）三级级联
- **理由**：① [SA:BR-016] 强制多路径；② 调研报告 NLI-01 已给三角对比；③ 异构 LLM 法官防 R-16 自恋偏差
- **拒绝的替代方案**：单层 LLM 法官 — 成本高 + 仍可能自恋偏差
- **影响范围**：M-003 抗幻觉网关 + DE-019/DE-020 + 性能 NFR
- **来源标注**：[SA:BP-007] + [调研报告:NLI-01 HaluGate, R-16]

## ADR-004 RAG 复杂度路由分流（80% / 20%）
- **状态**：已接受（阈值待 POC 验证）
- **内容**：80% 标准 RAG / 20% 代理 RAG，判定规则：实体数 ≥3 OR 跨段关键词 OR query length ≥30 token
- **理由**：① [SA:BR-029] 约束；② 调研报告 RI-NEW-4 已给三段判定起点；③ 边界置信度低走安全侧
- **拒绝的替代方案**：单一规则判定（query length ≥20 token）— 准确度不足
- **影响范围**：M-005 RAG + DE-010 RAG 实例 + DE-031/DE-032 评估
- **来源标注**：[SA:BP-013] + [调研报告:RI-NEW-4]

## ADR-005 引入全局循环计数器（max_total_rounds=5）
- **状态**：已接受
- **内容**：M-005 引入全局 `max_total_rounds=5` 计数器，覆盖 RAG 重检索 + 抗幻觉抗重检索的联合循环
- **理由**：① [SA:CE-010] 识别死循环；② 单层重检索上限（≤3）不能阻止跨层联合
- **拒绝的替代方案**：让 BP-013 和 BP-007 各自计数 — 仍可能联合超限
- **影响范围**：M-005 Pipeline 编排 + M-003 抗幻觉
- **来源标注**：[SA:CE-010 修复]

## ADR-006 FSRS 卡片 Again 节流（5min/卡）
- **状态**：已接受
- **内容**：同一卡片 5 分钟内仅允许 1 次 "Again" 评分
- **理由**：① [SA:CE-004] 识别 Again 风暴；② BR-012 字段规则已定但未限制频率
- **拒绝的替代方案**：不限制 — 看板爆炸
- **影响范围**：M-002 教学引擎 + DE-015/DE-016
- **来源标注**：[SA:CE-004 修复]

## ADR-007 缓存键组合 = query_hash + semantic_top1_doc_id
- **状态**：已接受
- **内容**：M-005 缓存键组合 = query_hash + semantic_embedding_top1_doc_id，命中后做二次校验
- **理由**：① [SA:CE-020] 识别 hash 碰撞；② 极小概率但曾发生
- **拒绝的替代方案**：仅 query_hash — 碰撞风险
- **影响范围**：M-005 + DE-007 cache_key
- **来源标注**：[SA:CE-020 修复]
