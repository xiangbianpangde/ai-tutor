## ADR-001 架构模式：分层 + 插件化 + 事件总线
- 状态：已接受
- 决策：采用混合架构（分层为核心 + 插件化注入可替换引擎 + 事件总线解耦 WS/FSM/兜底）
- 理由：满足 BR-002 单进程 + BR-003 5 类中间件 + WS ≤1s 实时性 + 翻译/NLI 可插拔
- 拒绝方案：纯微服务（违背单用户定位 / 运维成本高）
- 影响：M-001~M-017 全部模块、CI 流程、桌面端打包
- 来源：[TD推断:依据=灵魂 4.8 模式库] + [SA:BR-002/003/007]

## ADR-002 单进程承载（FastAPI + asyncio）
- 状态：已接受
- 决策：4 个原 MCP server 引擎合并到 FastAPI 单进程
- 理由：BR-002 明确要求；简化部署；asyncio 可承载 21 个流程
- 拒绝方案：多进程（端口管理复杂 / 进程间通信成本）
- 影响：M-001 服务入口；所有 5 类中间件
- 来源：[SA:BR-002] + [SA:BP-001]

## ADR-003 5 类中间件强制装配
- 状态：已接受
- 决策：Session/Cache/Monitor/Pipeline/RAG 必须全部注册
- 理由：BR-003 PRD 强制；F-002 验收要求
- 拒绝方案：可选装配（影响 OpenAPI 一致性）
- 影响：M-004~M-008 / M-001 启动流程
- 来源：[SA:BR-003] + [SA:BP-002]

## ADR-004 缓存双后端（SQLite 默认 / Redis 可选）
- 状态：已接受
- 决策：默认 SQLite；生产模式 Redis 不可用时降级 SQLite + WARN
- 理由：BR-006 + 调研 RI-010；本地优先 + 单用户场景
- 拒绝方案：Redis 强制（增加单用户部署成本）
- 影响：M-005 Cache 中间件
- 来源：[SA:BR-006] + [SA:EX-005]

## ADR-005 90% FSM + 10% LLM 兜底
- 状态：已接受
- 决策：90% 状态机 + 10% LLM 兜底（带 trace_id + 审计）
- 理由：BR-009/010 调研 S-019/DSM-02/06/39
- 拒绝方案：纯 LLM（成本高 / 不可控）/ 纯 FSM（覆盖率低）
- 影响：M-009 教学编排 / M-007 Pipeline
- 来源：[SA:BR-009/010] + [SA:AR-009]

## ADR-006 NLI 100% 带源
- 状态：已接受
- 决策：NLI 评分 < 0.7 触发重检索 ≤ 3 轮；阈值未达标注"无法确认" + 切 web 搜索
- 理由：BR-016 抗幻觉 100% 带源；BR-017/018 重检索上限
- 拒绝方案：纯 NLI（部署成本高）/ 纯 LLM（不可解释）
- 影响：M-008 (NLI 子) / M-007 Pipeline
- 来源：[SA:BR-016~018] + [SA:BP-007]

## ADR-007 FSRS Again 节流（5min/次）
- 状态：已接受
- 决策：同卡片 5 分钟内仅允许 1 次 Again
- 理由：CE-004 反例驱动；防看板爆炸
- 拒绝方案：无节流（CE-004 复现）
- 影响：M-011 FSRS 调度 / DE-016 字段
- 来源：[SA:CE-004] + [SA:BR-012]

## ADR-008 阶段 hysteresis（升/降档各需连续 2 天）
- 状态：已接受
- 决策：升档需连续 2 天 >80%；降档需连续 2 天 <60%
- 理由：CE-005 反例驱动；防档位跳变
- 拒绝方案：硬边界（CE-005 复现）
- 影响：M-012 阶段校准 / DE-018 字段
- 来源：[SA:CE-005] + [SA:BR-014]

## ADR-009 打包：覆盖率硬约束 / 体积软约束
- 状态：已接受
- 决策：覆盖率（≥80%）CI 阻断；体积 CLI < 50MB / GUI < 200MB 改 warn only
- 理由：CE-011 跨流程风险；仲裁覆盖率优先
- 拒绝方案：双硬约束（CE-011 复现）
- 影响：M-016 红线编排 / M-015 打包调度
- 来源：[SA:CE-011] + [SA:BR-032/046]
