# 长期演进路线图 — AITutor V3.1

> V3.1 起点 → V4.x 演进（5 阶段，含回滚策略）

---

## V3.2 [近期 - Q3 2026]

**触发条件**：
- 用户数 > 100（自报） / API QPS > 10（监控）
- 当前打包体积 < 50MB CLI 目标达成率 ≥ 80%（DE-033 监控）

**新增**：
- M-008 子能力拆分（NLI 独立子模块 + 本地索引独立子模块）
- M-016 横切治理拆分（Redline 闸门 / Error Hub 分开）

**废弃**：
- 无

**迁移策略**：
- 灰度：先 10% 用户启用新拆分
- 双写：新旧模块并行写 DE-046/047

**回滚策略**：
- 触发：拆分后 DE-046 写入失败率 > 1%
- 步骤：路由切回旧 M-008 + 保留新模块只读
- 数据保障：DE-046 旧值仍可用
- 预计回滚时间：≤ 15min

**风险等级**：中
**来源**：[TD推断:依据=D7 简洁度收敛后内聚度提升]

---

## V3.5 [中期 - Q4 2026] GUI 形态确定

**触发条件**：
- AR-001 OC-1 PM 决策落地
- POC 完成（PDF+LLM+引擎桥接 验证 5 项）

**新增**：
- M-003 适配器根据决策增加对应 GUI 形态

**废弃**：
- 无（GUI 形态三选一通过热加载切换）

**迁移策略**：
- 灰度：5% 用户先行体验
- 配置化：M-003 形态选择走 .env `CLIENT_GUI=tauri|electron|pywebview`

**回滚策略**：
- 触发：GUI 启动失败率 > 2%
- 步骤：env 切回 CLI-only + 修复 GUI 后重发
- 预计回滚时间：≤ 5min

**风险等级**：高（GUI 形态有 Windows Defender / 体积风险）
**来源**：[SA:AR-001] + [SA:BR-035] + [SA:CE-011]

---

## V4.0 [中远期 - Q2 2027] 多用户 + 云端

**触发条件**：
- B-001（云端备份）/ B-002（多用户）进入 P0
- 单用户 → 多用户切换决策

**新增**：
- M-026 鉴权服务（独立 user_id 分区）
- M-027 同步 worker（云端 S3）
- DE-049 user_account, DE-050 sync_log

**废弃**：
- 无

**迁移策略**：
- 双写：单用户表 + 多用户分区表（30 天过渡）
- 蓝绿：旧单用户实例保留只读 7 天

**回滚策略**：
- 触发：分区写入异常或鉴权失败率 > 0.5%
- 步骤：env 切回单用户 + 数据回灌
- 预计回滚时间：≤ 30min

**风险等级**：高
**来源**：[SA:AR-004/005] + backlog B-001/002

---

## V4.5 [远期 - 2027+] 智能路由 POC 落地

**触发条件**：
- RI-NEW-4 POC 阈值实测完成
- fallback_rate < 15%（监控）

**新增**：
- M-008 子能力 智能路由判定器（基于特征工程）
- DE-051 routing_features

**废弃**：
- BR-020 默认关键字匹配路由（保留作为 fallback）

**迁移策略**：
- 灰度：先 5% 流量走新路由
- A/B：与旧路由对比 NLI 评分

**回滚策略**：
- 触发：新路由 fallback_rate > 旧路由 1.5x
- 步骤：env 切回默认路由
- 预计回滚时间：≤ 5min

**风险等级**：中
**来源**：[SA:BR-020] + [SA:AR-016] + [SA:CE-010]

---

## V5.0 [战略 - 2028+] 知识图谱外化

**触发条件**：
- L5 知识图谱体量 > 10万节点
- 社区共建需求

**新增**：
- M-028 知识图谱服务（独立 Neo4j/PostgreSQL+AGE）
- 第三方插件接口（SP-API v2）

**废弃**：
- L5 内存图谱（DE-011 拆为外部引用）

**迁移策略**：
- 双写：内存图谱 + 外部图谱（90 天）
- 停机：双写一致后切读

**回滚策略**：
- 触发：外部图谱查询延迟 > 1s
- 步骤：env 切回内存图谱
- 数据保障：内存图谱继续累计
- 预计回滚时间：≤ 1h

**风险等级**：高
**来源**：[TD推断:依据=backlog B-005~007 + S-019 移交]
