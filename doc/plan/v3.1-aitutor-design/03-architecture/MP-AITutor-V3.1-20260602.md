## 三、模块接口契约（关键 8 条）

### IF-001 服务启动
- 模块：M-001 → 调用方：M-002 / M-003
- 复杂度：复杂事务(3)
- 输入：config_path (str, pyproject.toml+.env)
- 输出：app (FastAPI), middleware_status (DE-004)
- 错误码：E00101 依赖缺失 / E00102 端口冲突 / E00103 旧库不兼容 / E00106 中间件初始化失败
- 性能：启动 ≤ 30s
- 来源：[SA:BP-001/002] + [SA:EX-001~006]

### IF-002 学习回合
- 模块：M-009 → 调用方：M-002
- 复杂度：复杂事务(3)
- 输入：user_id, session_id, action (learn/review/rest)
- 输出：next_step, fsrs_card_update, feynman_question, rest_prompt
- 错误码：E00901 LLM 评分失败 / E00902 FSM 卡死 / E00903 FSRS 版本低
- 性能：单回合 ≤ 5s
- 来源：[SA:BP-003/004/005/006]

### IF-003 RAG 检索
- 模块：M-008 → 调用方：M-009 / M-002
- 复杂度：复杂事务(3)
- 输入：query, query_features, threshold
- 输出：top_k_chunks, nli_score, sources, route_decision
- 错误码：E00801 重检索 3 轮仍 < 0.7 / E00802 NLI 不可用 / E00803 重路由
- 性能：单次 ≤ 10s
- 来源：[SA:BP-007/008/011]

### IF-004 数据入库
- 模块：M-014 → 调用方：M-002
- 复杂度：标准操作(2)
- 输入：pdf_path 或 chunk_text
- 输出：doc_id, status (READY/FAILED), chunk_count
- 错误码：E01401 pdf2zh 失败 / E01402 LLM 超时 / E01403 clean 后重复率仍 >30%
- 性能：10 页 PDF ≤ 60s
- 来源：[SA:BP-009]

### IF-005 打包构建
- 模块：M-015 → 调用方：M-002 / CI
- 复杂度：复杂事务(3)
- 输入：platform, format
- 输出：artifact_path, size_bytes, sha256, build_log
- 错误码：E01501 体积超目标 / E01502 工具链不兼容
- 性能：单平台 ≤ 10min
- 来源：[SA:BP-014]

### IF-006 红线检测
- 模块：M-016 → 调用方：CI / M-003
- 复杂度：标准操作(2)
- 输入：tool (RUFF/IMPORT_LINTER/REDOCLY/PRE_COMMIT/PYTEST)
- 输出：exit_code, violation_count, raw_output, fix_url
- 错误码：E01601 退出码非 0 / E01602 合约违反 / E01603 覆盖率不达标
- 性能：4 工具并行 ≤ 5min
- 来源：[SA:BP-021] + [SA:BR-046~050]

### IF-007 长期记忆
- 模块：M-013 → 调用方：M-009 / M-008
- 复杂度：标准操作(2)
- 输入：entity_id, fact, source_trace_id
- 输出：stored (bool), entity_type
- 错误码：E01301 LLM 提取失败 / E01302 LRU 淘汰触发
- 性能：单写 ≤ 100ms
- 来源：[SA:BP-013] + [SA:BR-029]

### IF-008 WS 推送
- 模块：M-002 → 调用方：M-009 / M-011 / M-012
- 复杂度：简单查询(1)
- 输入：user_id, event_type, payload
- 输出：delivered (bool), connection_id
- 错误码：E00201 连接断开 / E00202 超限拒绝
- 性能：端到端 ≤ 1s
- 来源：[SA:BP-010] + [SA:BR-007]
