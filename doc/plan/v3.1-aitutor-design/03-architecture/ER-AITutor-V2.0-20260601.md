> 触发条件均为可量化指标

## V-1 阶段：性能瓶颈突破（短期：3-6 个月内）

| 字段 | 内容 |
|------|------|
| 触发条件 | 1) 1000 文档检索 P95 > 2s [BR-032]；2) FSRS 调度扫描 > 5s；3) LLM 调用失败率 > 5% |
| 新增模块 | M-011（向量化缓存层 - 语义 embedding 索引到 sqlite-vec）；M-012（LLM 熔断器 - 断路器模式） |
| 废弃模块 | 无 |
| 迁移策略 | 灰度：5% → 25% → 50% → 100% 流量切到 M-011；通过监控指标验证 |
| 回滚策略 | 触发条件：P95 恶化 > 20% / 错误率上升 > 1%；步骤：流量切回 0% → 数据双写 M-007/M-011 → 保留 30 天；预计回滚 5 分钟 |
| 风险等级 | 中 |

| 风险等级 | 高（涉及安全） |

| 风险等级 | 中 |

---

## 跨阶段通用回滚原则

1. **数据双写期**：所有演进阶段必须保持旧存储双写 ≥ 7 天
2. **灰度可逆**：流量切回必须支持秒级回退（不依赖冷启动）
3. **配置回退**：所有新增配置项必须有 `enabled=false` 默认值
4. **监控先行**：演进阶段必须先部署监控指标，再开始灰度
5. **回滚演练**：每次发布前 1 周必须做回滚演练（QA 团队）
