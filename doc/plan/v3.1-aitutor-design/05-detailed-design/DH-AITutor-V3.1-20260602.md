## DD 洞察（5 条，本轮注入）

### INSIGHT-DD-001 M-008 RAG 子能力内聚度过低
**类型**：设计模式误用
**描述**：M-008 当前承担 4 大子能力，TD-AR-005 记录内聚度 3/6（最低）
**缓解**：子能力命名空间隔离（`m008.routing/nli/indexing/translation`）+ Import Linter independence contract 强制
**状态**：已记录到 DDR-002

### INSIGHT-DD-002 PDF 翻译 + NLI 推理存在 CPU 争抢
**类型**：性能瓶颈预判
**描述**：M-014（512MB+ThreadPool）与 M-008（1.5GB+transformers）并发争抢
**缓解**：M-001 启动期绑定 NLI 到 CPU 0 亲和性；M-014 走 ThreadPool CPU 1-3
**状态**：承接 AR INSIGHT-AR-001

### INSIGHT-DD-003 长期记忆 LRU 误删风险
**类型**：技术债务 + 异常处理
**描述**：M-013 LRU 淘汰最旧 10% 可能误删关键事实
**缓解**：EX-013 异常处理策略——淘汰前 audit_log + 用户可读 markdown 导出
**状态**：已记录到 EX-013

### INSIGHT-DD-004 WS 重连风暴下事件总线压力
**类型**：并发安全
**描述**：max_connections=1000 + 状态补发 30s + 心跳 5s；1000 个断连同时重连将堵塞事件总线
**缓解**：指数退避（base=1s, max=30s, jitter±30%）+ 连接级别优先级队列
**状态**：已记录到 EX-002

### INSIGHT-DD-005 4 工具链 Ruff 1.0 升级窗口
**类型**：技术债务
**描述**：Ruff 1.0 前 API 破坏性变更
**缓解**：CS-NNN 风格指南固化为 .ruff.toml 全规则集；CI 锁版本不升级；V3.2 走 TDD 渐进式
**状态**：已记录到 EX-016
