## 后端与中间件（BR-001 ~ BR-010）

### BR-001 服务端禁 MCP 协议引用
- **规则描述**：服务端代码（`backend/`）不得引用 `mcp.server` 协议；客户端 SDK 引用允许
- **适用范围**：F-001
- **优先级**：高
- **冲突处理**：与"通过 MCP 暴露能力"互斥 → NB-1
- **来源标注**：[PRD:F-001] + [调研报告:S-001]

### BR-002 单进程承载所有引擎
- **规则描述**：4 个原 MCP server 引擎（knowledge/tutoring/digest/sync）合并到 FastAPI 单进程
- **适用范围**：F-001
- **优先级**：高
- **冲突处理**：与"独立部署每个引擎"互斥
- **来源标注**：[PRD:F-001]

### BR-003 中间件 5 类强制装配
- **规则描述**：Session/Cache/Monitor/Pipeline/RAG 五类中间件必须全部注册
- **适用范围**：F-002
- **优先级**：高
- **冲突处理**：可单独禁用某类（配置项）但默认全启用
- **来源标注**：[PRD:F-002]

### BR-004 监控必带 trace_id
- **规则描述**：所有埋点必须含 trace_id (32 hex) + span_id (16 hex)
- **适用范围**：F-002, F-009
- **优先级**：高
- **冲突处理**：无
- **来源标注**：[PRD:NFR-5] + [调研报告:S-016]

### BR-005 缓存语义阈值
- **规则描述**：Cache 命中语义相似度阈值 = 0.85~0.95
- **适用范围**：F-002, F-009
- **优先级**：中
- **冲突处理**：阈值超范围需重启服务
- **来源标注**：[调研报告:S-013]

### BR-006 缓存双后端降级路径
- **规则描述**：默认 SQLite；启用生产模式且 Redis 不可用时降级到 SQLite + WARN
- **适用范围**：F-002
- **优先级**：中
- **冲突处理**：无
- **来源标注**：[调研报告:S-013] + [PRD:F-002]

### BR-007 v1 数据库兼容
- **规则描述**：旧 `data/tutor.db` 拷贝后所有 v1 测试通过
- **适用范围**：F-001
- **优先级**：高
- **冲突处理**：schema 不兼容走 EX-001 迁移
- **来源标注**：[PRD:F-001 验收②]

### BR-008 Pipeline 注入顺序可见
- **规则描述**：Pipeline 步骤顺序在 OpenAPI schema 可见
- **适用范围**：F-002
- **优先级**：中
- **冲突处理**：无
- **来源标注**：[PRD:F-002 验收④]

### BR-009 短期记忆用 ConversationSummaryBufferMemory
- **规则描述**：短期记忆实现 = ConversationSummaryBufferMemory（早期摘要+近期原文）
- **适用范围**：F-002, F-010
- **优先级**：中
- **冲突处理**：无
- **来源标注**：[调研报告:S-011]

### BR-010 长期记忆用 LangGraph Store
- **规则描述**：长期记忆实现 = LangGraph Store + JSON 持久化
- **适用范围**：F-002, F-010
- **优先级**：中
- **冲突处理**：无
- **来源标注**：[调研报告:S-011]

## 教学策略（BR-011 ~ BR-022）

### BR-011 费曼题必做
- **规则描述**：每节学完必须生成费曼复述题
- **适用范围**：F-003.1
- **优先级**：高
- **冲突处理**：与 NB-9 主观题不冲突
- **来源标注**：[PRD:F-003.1]

### BR-012 FSRS 调度必含 4 字段
- **规则描述**：stability / difficulty / retrievability / next_due 必须在 SQLite 可查
- **适用范围**：F-003.2
- **优先级**：高
- **冲突处理**：无
- **来源标注**：[PRD:F-003.2 验收②]

### BR-013 py-fsrs 版本下限
- **规则描述**：py-fsrs ≥ 0.16.0
- **适用范围**：F-003.2
- **优先级**：高
- **冲突处理**：低于版本号 EX-011 阻断
- **来源标注**：[调研报告:S-002]

### BR-014 阶段档位自适应
- **规则描述**：正确率 < 60% → 1.0；60%~80% → 1.5；> 80% → 2.0
- **适用范围**：F-003.3, F-016
- **优先级**：中
- **冲突处理**：样本不足维持当前档
- **来源标注**：[PRD:F-003.3, F-016]

### BR-015 25 分钟静默触发休息
- **规则描述**：连续学习 ≥ 25 分钟触发 toast
- **适用范围**：F-003.4
- **优先级**：中
- **冲突处理**：勿扰模式仅记录不弹
- **来源标注**：[PRD:F-003.4]

### BR-016 抗幻觉必走多路径
- **规则描述**：抗幻觉走 HaluGate 级联（NLI 40% + SLM 55% + LLM 5%）
- **适用范围**：F-003.5
- **优先级**：高
- **冲突处理**：某层不可用降级而非跳过
- **来源标注**：[PRD:F-003.5] + [调研报告:NLI-01 HaluGate, S-012]

### BR-017 100% 事实带源
- **规则描述**：事实性回答 100% 附带 source 引用
- **适用范围**：F-003.5
- **优先级**：高
- **冲突处理**：无法验证则标记"无法验证"
- **来源标注**：[PRD:F-003.5 验收④]

### BR-018 LLM 法官 ≥ 2 独立打分
- **规则描述**：高歧义声明需 ≥ 2 个 LLM 法官独立打分
- **适用范围**：F-003.5
- **优先级**：中
- **冲突处理**：防 R-16 自恋偏差
- **来源标注**：[调研报告:R-16, NLI-26]

### BR-019 重检索上限
- **规则描述**：重检索循环 ≤ 2~3 次 + 提前退出
- **适用范围**：F-003.5, F-008
- **优先级**：高
- **冲突处理**：超出报错给用户
- **来源标注**：[PRD:F-003.5, F-008]

### BR-020 90% 状态机 + 10% LLM 兜底
- **规则描述**：教学流程 = 90% 确定性状态机 + 10% LLM 兜底
- **适用范围**：F-003.6
- **优先级**：高
- **冲突处理**：与 NB-6 个性化推荐互斥
- **来源标注**：[PRD:F-003.6, NB-6, OC-10] + [调研报告:S-019]

### BR-021 兜底必带审计
- **规则描述**：LLM 兜底调用必带 trace_id + 输入/输出/评分写入 audit_log
- **适用范围**：F-003.6
- **优先级**：高
- **冲突处理**：审计失败阻断兜底
- **来源标注**：[PRD:F-003.6, OC-10] + [调研报告:S-019, R-09]

### BR-022 状态机状态转移图可复现
- **规则描述**：流程引擎状态转移图可在文档中复现
- **适用范围**：F-003.6
- **优先级**：中
- **冲突处理**：无
- **来源标注**：[PRD:F-003.6 验收⑤]

## 数据管线与 RAG（BR-023 ~ BR-029）

### BR-023 MinHash Jaccard 阈值
- **规则描述**：去重 MinHash Jaccard = 0.85
- **适用范围**：F-004, F-006

- **冲突处理**：去重过度调高到 0.90
- **来源标注**：[调研报告:S-008]

### BR-024 LLM 相关性保留率
- **规则描述**：清洗步骤 LLM 相关性过滤保留率 = 70%
- **适用范围**：F-004, F-006
- **优先级**：中
- **冲突处理**：保留率过低触发人工抽样
- **来源标注**：[调研报告:S-008]

### BR-025 本地资料优先
- **规则描述**：本地资料路径优先级 > 在线搜索
- **适用范围**：F-004, F-015
- **优先级**：中
- **冲突处理**：离线模式完全本地
- **来源标注**：[PRD:F-004 验收④, F-015]

### BR-026 PDF 入库偏差
- **规则描述**：chunks 数量与原文段落数偏差 ≤ 5%
- **适用范围**：F-004
- **优先级**：中
- **冲突处理**：偏差超限触发告警
- **来源标注**：[PRD:F-004 验收③]

### BR-027 pdf2zh 翻译 SLA
- **规则描述**：10 页中文 PDF 翻译 ≤ 60s
- **适用范围**：F-007
- **优先级**：中
- **冲突处理**：超时不阻塞，进度推送
- **来源标注**：[PRD:F-007 验收①]

### BR-028 DeepSeek 3 次失败降级
- **规则描述**：DeepSeek 失败 3 次切 LM Studio
- **适用范围**：F-007
- **优先级**：高
- **冲突处理**：降级后语种校验
- **来源标注**：[调研报告:S-009]

### BR-029 复杂度路由分流
- **规则描述**：80% 标准 RAG / 20~30% 代理 RAG
- **适用范围**：F-008
- **优先级**：中

## 规则冲突检测

| 规则对 | 冲突点 | 仲裁 |
|--------|--------|------|
| BR-020 vs BR-021 | 状态机 vs 兜底 | BR-020 是路径，BR-021 是兜底审计；不冲突，BR-021 是 BR-020 的子规则 |
| BR-019 vs BR-029 | 重检索上限 | 一致（都 ≤ 3 次） |
| BR-005 vs BR-031 | 缓存阈值 vs 性能 | BR-005 阈值越低命中率越高但准确度越低；BR-031 是结果约束 |
| BR-018 vs BR-016 | LLM 法官数 | BR-016 是路径，BR-018 是裁决质量强化；不冲突 |
| BR-014 vs BR-013 | 档位 vs FSRS | 不冲突，BR-013 是字段约束，BR-014 是档位规则 |

**无逻辑矛盾。**
