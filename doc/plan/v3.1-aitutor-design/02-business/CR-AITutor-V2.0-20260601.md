## CR-001 [阻塞] GUI 形态三选一（OC-1 / S-017）
- **关联PRD**：F-005 / F-011 / 成功指标 S6
- **歧义描述**：A. Electron（120-250MB / 1-5s 启动 / 内存 100-300MB / 生态成熟） / B. Tauri（2-15MB / 0.1-0.5s 启动 / 内存 20-100MB / 需 Rust 2-4 周学习 + 重写 PDF 解析和学习引擎桥） / C. PyWebView（Python 原生 / js_api 直暴露 Python 对象 / 体积最小 / Windows WebView2 兼容问题 + 生态最弱）
- **SA 建议方案**：建议 POC 1-2 天实测关键路径：① PDF 解析 (pdf2zh) ② LLM 客户端 (OpenAI/Anthropic SDK) ③ 学习引擎 IPC 桥；选型维度 = 体积 / 启动 / 内存 / 二次开发成本
- **备选方案**：保守选 Electron（生态成熟）；激进选 Tauri（轻量）；折中选 PyWebView（与 Python 后端天然集成）
- **需要确认的问题**：
  1. PM 是否在 1 周内决策？否则 SA 默认按 Electron 实现
  2. 是否接受体积 ≤ 250MB（软上限）作为可接受 trade-off？
  3. 是否分配 1-2 天 POC 时间窗口给 SA-001 + AR-001？
- **风险等级**：高
- **阻塞状态**：阻塞 F-005 / F-011 / S6 验收细化；不阻塞 SA 阶段分析（保留 3 套接口）
