# 异常场景清单 — AITutor V2.0（终版）

> 覆盖要求：核心流程 ≥ 4/5（5 类异常）；标准流程 ≥ 3/5；辅助流程 ≥ 2/5
> 5 类异常：输入异常 / 状态异常 / 通信异常 / 资源异常 / 逻辑异常

---

## BP-001 后端单体化（核心）

### EX-001 旧库 schema 不兼容 [状态异常]
- **关联流程**：BP-001 步骤 3
- **触发条件**：v1 SQLite schema 与 v2 不匹配（如缺字段/字段类型变更）
- **影响范围**：阻断服务启动；用户无法访问历史数据
- **处理策略**：自动调用 `migrate_v1_to_v2()`；备份原库到 `data/tutor.db.bak.YYYYMMDD`
- **恢复方式**：迁移失败 → 需人工执行迁移脚本
- **来源标注**：[PRD:F-001] + [SA推断:依据=数据库迁移惯例]

### EX-002 端口冲突 [资源异常]
- **关联流程**：BP-001 步骤 5
- **触发条件**：8000 端口被占用
- **影响范围**：服务无法启动
- **处理策略**：自动递增重试 8001, 8002, 8003；仍冲突则报错
- **恢复方式**：需用户释放端口 / 手动指定端口
- **来源标注**：[PRD:F-001] + [SA推断:依据=端口管理惯例]

### EX-003 依赖缺失 [资源异常]
- **关联流程**：BP-001 步骤 1
- **触发条件**：uv 安装后部分二进制库（如 sentence-transformers）缺失
- **影响范围**：服务启动失败
- **处理策略**：doctor 命令检测 + 提示 `uv sync` 重装
- **恢复方式**：需用户手动重装
- **来源标注**：[PRD:F-011] + [SA推断:依据=依赖管理惯例]

### EX-004 配置文件损坏 [输入异常]
- **关联流程**：BP-001 步骤 1
- **触发条件**：.env 文件格式错误 / 关键配置项缺失
- **影响范围**：服务无法启动
- **处理策略**：加载 .env.example 兜底 + WARN 日志
- **恢复方式**：需用户修正配置
- **来源标注**：[PRD:F-001] + [NFR-4]

### EX-005 旧库损坏 [逻辑异常]
- **关联流程**：BP-001 步骤 3
- **触发条件**：SQLite 文件 CRC 校验失败
- **影响范围**：阻断启动
- **处理策略**：自动从 `.bak` 恢复最近一次备份
- **恢复方式**：无备份时不可恢复
- **来源标注**：[SA推断:依据=数据完整性]

## BP-003 / BP-004 / BP-005 教学策略（核心）

### EX-009 LLM 调用超时 [通信异常]
- **关联流程**：BP-003 步骤 4
- **触发条件**：provider API 响应 > 30s
- **影响范围**：费曼题评分延迟
- **处理策略**：重试 1 次 → 降级到更小模型 → 仍失败走 10% 兜底
- **恢复方式**：自动恢复
- **来源标注**：[PRD:F-003.1] + [调研报告:R-02]

### EX-010 LLM 评分异常低 [逻辑异常]
- **关联流程**：BP-003 步骤 5
- **触发条件**：评分 < 60 连续 2 轮
- **影响范围**：用户学习进度受影响
- **处理策略**：标记"未掌握" + FSRS 重学调度
- **恢复方式**：用户重做
- **来源标注**：[PRD:F-003.1] + [SA推断:依据=学习闭环]

### EX-011 py-fsrs 版本过低 [输入异常]
- **关联流程**：BP-004 步骤 2
- **触发条件**：py-fsrs < 0.16.0
- **影响范围**：FSRS 调度字段缺失
- **处理策略**：阻断 + 提示 `uv add 'py-fsrs>=0.16.0'`
- **恢复方式**：用户升级依赖
- **来源标注**：[调研报告:RI-002, S-002] + [RI-NEW-2]

### EX-012 复习卡片数据冲突 [状态异常]
- **关联流程**：BP-004 步骤 3
- **触发条件**：并发更新同一卡片 FSRS 字段
- **影响范围**：复习进度回退
- **处理策略**：SQLite WAL + 乐观锁；冲突时后者覆盖前者 + WARN
- **恢复方式**：自动（最新写赢）
- **来源标注**：[SA推断:依据=并发控制]

### EX-013 样本不足无法判定档位 [输入异常]
- **关联流程**：BP-005 步骤 1
- **触发条件**：用户使用 < 7 天
- **影响范围**：阶段档位维持
- **处理策略**：维持当前档位 + INFO 日志
- **恢复方式**：积累样本
- **来源标注**：[PRD:F-003.3]

### EX-014 Monitor 计时器漂移 [逻辑异常]
- **关联流程**：BP-006 步骤 1
- **触发条件**：系统时间跳变 / NTP 失效
- **影响范围**：25 分钟计时不准
- **处理策略**：用 monotonic clock 重置基准
- **恢复方式**：自动
- **来源标注**：[SA推断:依据=时间可靠性]

### EX-015 NLI 模型不可用 [资源异常]
- **关联流程**：BP-007 步骤 2
- **触发条件**：DeBERTa-v3-large-mnli 模型文件缺失 / 推理失败
- **影响范围**：第一层 NLI 过滤失效
- **处理策略**：跳过 NLI 走 SLM 法官 + WARN
- **恢复方式**：自动 fallback
- **来源标注**：[PRD:F-003.5] + [调研报告:S-012, R-03, RI-NEW-1]

### EX-016 LLM 法官调用失败 [通信异常]
- **关联流程**：BP-007 步骤 4
- **触发条件**：所有 LLM provider 不可用
- **影响范围**：高歧义声明无最终评分
- **处理策略**：标记"无法验证" + 不阻塞回答
- **恢复方式**：provider 恢复后重试
- **来源标注**：[PRD:F-003.5] + [调研报告:R-16]

### EX-017 重检索循环超限 [资源异常]
- **关联流程**：BP-007 步骤 6
- **触发条件**：重检索 3 轮后覆盖度仍 < 70%
- **影响范围**：回答可能不全
- **处理策略**：返回"已尽力检索" + 部分结果
- **恢复方式**：用户调整查询
- **来源标注**：[PRD:F-008]

### EX-018 兜底连续触发 [逻辑异常]
- **关联流程**：BP-008 步骤 2
- **触发条件**：同一状态连续 3 次触发兜底
- **影响范围**：状态机规则缺失
- **处理策略**：写入 `state_machine_proposals` 表 + 通知开发者
- **恢复方式**：开发者 review 后沉淀为新规则
- **来源标注**：[PRD:F-003.6] + [调研报告:S-019]

### EX-019 审计日志写入失败 [资源异常]
- **关联流程**：BP-008 步骤 4
- **触发条件**：audit_log 表写满 / 磁盘满
- **影响范围**：合规性受损
- **处理策略**：阻断兜底调用 + 强制清理
- **恢复方式**：人工清理
- **来源标注**：[PRD:F-003.6] + [调研报告:R-09]
