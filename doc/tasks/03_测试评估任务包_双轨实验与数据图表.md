# 测试评估任务包：双轨实验与数据图表

> **面向成员**：测试与评估员（新手友好型，理工/经管背景均可）
> **前置技能要求**：无需编写深奥底层代码，只需会使用 Python 基础命令、Excel 或 Python 绘图（matplotlib/seaborn），以及具备基本的科学对比实验常识。
> **目标**：用硬核的**“客观对比实验 + 真实受试者问卷（SUS）”**双轨数据，为比赛论文和答辩 PPT 提供具有学术严谨性与强大说服力的图表证据，彻底封死评委“你们怎么证明系统有效？”的刁钻提问！

## 一、 任务目标与交付物

### 1. 核心职责
在创新创业和科技竞赛中，评委最反感“纯画大饼”或自称“效果拔群”却无实验数据支撑的项目。你的任务是用客观数据证明系统的先进性：

#### 轨一：三门学科客观 Benchmark 评测实验
1. **准备 3 份标准语料（每份 3,000~8,000 字）**：
   * 计算机学科：《操作系统：进程与虚拟内存》
   * 理工基础科：《大学物理：热力学第二定律与熵增》
   * 经管通识科：《西方微观经济学：弹性与完全竞争市场》
2. **实验 A：知识图谱构建质量与抗噪声对比**
   * 统计系统建图抽取出的概念总数、关键关系数。
   * 验证系统的 **NoiseGate 噪声过滤红线**（噪声标题必须 `< 5%`），对比普通未清洗大模型（常见噪音率高达 25%~40%）。
3. **实验 B：判分系统抗作弊与防欺骗实验（Adversarial Attack）**
   * 准备 10 道典型知识问答题，分别用 3 种恶意手法作答：
     * ① “车轱辘废话”攻击（长篇大论但毫无实质内容）
     * ② “偷换概念”攻击（回答完全不相干的内容）
     * ③ “极简正确”作答（只有核心几个词）
   * 验证系统是否能准确识别废话并判定为 incorrect，同时对极简正确给予高分（系统内置了 [FIX-D](file:///Users/xbpd/Projects/ai-tutor/STATUS.md#L33) 与 [FIX-L](file:///Users/xbpd/Projects/ai-tutor/STATUS.md#L70) 防御算法，你负责将这套防御能力测出具体数据！）。

#### 轨二：真实受试者体验问卷与可用性统计（User Study）
1. 组织 10~15 位身边同学试用系统 15 分钟（体验从导入资料、看知识图谱、做测验到生成导图全流程）。
2. 填写标准 **SUS（系统可用性量表，System Usability Scale，国际权威 10 题标准）** 与心流焦虑度问卷。
3. 统计平均得分（目标：SUS 总分 `>= 80 分`，达到优秀 Grade A 等级）。

### 2. 交付成果物
* **三份标准测试语料**：存放于 `examples/benchmarks/` 目录。
* **一份《AI-Tutor 核心性能与可用性量化评测报告.md》**（含实验参数、测试结果、统计表格）。
* **至少 4 张高清数据可视化对比图表（PNG 格式）**，直接提供给写手插入论文和 PPT：
  1. `chart1_noise_comparison.png`：本系统 vs 传统大模型知识图谱噪声率对比柱状图。
  2. `chart2_attack_robustness.png`：面对 3 种作弊攻击时的判分准确率对比图。
  3. `chart3_sus_evaluation.png`：15 位真实受试者 SUS 可用性评分分布箱线图/柱状图。
  4. `chart4_bkt_convergence.png`：不同水平学生掌握概念的 BKT 学习收敛曲线图。

## 三、 新手极速上手学习计划（2 周分解）

### 阶段 1：跑通测试与语料准备（Day 1 ~ Day 3）
* **第一天：掌握基本测试命令**
  * 在终端运行：
    ```bash
    uv run pytest backend/tests/test_local_judge.py -v
    ```
  * 观察终端输出的 PASSED，搞懂每一项测试在验证什么。
* **第二天：准备 3 份学科语料**
  * 寻找一本熟悉的教材或网上高质量 Markdown 文档，提取 3 个不同专业的章节，规范各级 `#` 和 `##` 标题，保存到 `examples/benchmarks/01_os.md`, `02_physics.md`, `03_economics.md`。
* **第三天：试运行建图**
  * 在 Web 端导入这 3 份语料，肉眼观察生成的知识概念列表，记录概念总数，挑选出有没有奇怪的无用标题（如“引言”、“参考文献”等）。

### 阶段 2：设计作弊测试集与统计抗攻击率（Day 4 ~ Day 7）
* 设计一个简单的 Python 评估脚本（例如保存为 `scripts/eval_scorer_robustness.py`），或者在 Excel 表格中记录：
  | 测试题 | 学生回答类型 | 实际输入内容 | 系统判定结果 | 是否符合预期 |
  |---|---|---|---|---|
  | 什么是死锁？ | 废话充字数 | 死锁是一个非常重要的问题，我们需要在生活中时刻注意死锁... | incorrect (0.1分) | ✅ 符合 |
  | 什么是死锁？ | 极简正确 | 互斥且循环等待资源不可抢占 | correct (0.95分) | ✅ 符合 |
  | 什么是死锁？ | 答非所问 | 今天天气真好我想去吃麻辣烫 | incorrect (0.0分) | ✅ 符合 |
* 统计 30 次对抗样本的拦截率（通常系统能达到 90%+ 拦截率！）。

### 阶段 3：受试者问卷与数据清洗（Day 8 ~ Day 12）
* **制作问卷星/腾讯问卷**，采用国际标准的 SUS 10 题量表（5 分制）：
  1. 我觉得我乐意经常使用这个系统。
  2. 我觉得这个系统过于复杂了。（反向题）
  3. 我觉得这个系统很容易上手。
  4. 我觉得需要专业技术人员的帮助我才能使用这个系统。（反向题）
  5. 我觉得系统中的各项功能整合得很好。
  6. 我觉得这个系统有太多的不一致性。（反向题）
  7. 我想象大多数人会很快学会使用这个系统。
  8. 我觉得这个系统使用起来很麻烦。（反向题）
  9. 我对使用这个系统感到很有信心。
  10. 在开始使用这个系统之前，我需要学习很多知识。（反向题）
* 收集 10~15 份数据后，按标准算法计算得分：
  * 奇数题分值 - 1；偶数题 5 - 分值；总和乘以 2.5 得到 0~100 分。

### 阶段 4：绘制高清图表并交付写手（Day 13 ~ Day 14）
* 使用 Python 运行简易脚本或 Excel 导出高清矢量图：
  ```python
  import matplotlib.pyplot as plt

  # 图 1：抗攻击识别率对比
  categories = ['答非所问', '车轱辘废话', '偷换概念', '概念混淆']
  raw_llm = [62, 45, 50, 58]
  ai_tutor = [98, 95, 92, 94]

  plt.figure(figsize=(7, 4))
  plt.bar([x - 0.2 for x in range(4)], raw_llm, width=0.4, label='通用大模型 (Baseline)')
  plt.bar([x + 0.2 for x in range(4)], ai_tutor, width=0.4, label='AI-Tutor (本文系统)')
  plt.xticks(range(4), categories)
  plt.ylabel('错误答案与攻击识别率 (%)')
  plt.title('判分防火墙与反向攻击防御鲁棒性对比')
  plt.legend()
  plt.tight_layout()
  plt.savefig('chart2_attack_robustness.png', dpi=300)
  ```
* 将生成的 PNG 交付给写手同学贴入申报书。
