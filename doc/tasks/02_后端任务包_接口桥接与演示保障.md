## 一、 任务目标与交付物

### 1. 核心职责
在 `backend/routers/` 目录下，目前的两个文件：
* [backend/routers/digest.py](file:///Users/xbpd/Projects/ai-tutor/backend/routers/digest.py)
* [backend/routers/sync.py](file:///Users/xbpd/Projects/ai-tutor/backend/routers/sync.py)
目前只是占位的空桩（只有 `/health` 端点）。你的任务是：
1. **补全 `digest` 路由**：
   * `GET /api/digest/formats`：列出支持的 7 种格式（思维导图、测验题、幻灯片、三角色对话、闪卡等）。
   * `POST /api/digest/generate`：接收科目 ID 与所需格式，调用现有逻辑生成产物。

2. **补全 `sync` 路由**：
   * `POST /api/sync/obsidian/push`：将产物导出写入本地指定文件夹或 Obsidian Vault。

3. **实现“高可靠比赛 Mock 兜底”**：
   * 在生成逻辑中加入环境判断：如果未配置 API Key 或开启了 `DEMO_MODE=1`，直接秒回高质量的预置题目与导图 Markdown，保证评委在看演示时**零网络延迟、零报错**！

### 阶段 2：桥接 Digest 测验生成逻辑（Day 4 ~ Day 7）
* **编写生成测验的端点**：
  ```python
  from fastapi import Body, Request
  from ..responses import ok

  @router.post("/quiz", summary="根据概念生成互动测验")
  async def generate_quiz(
      request: Request,
      concept_name: str = Body(..., embed=True),
      subject_id: str | None = Body(None, embed=True),
  ) -> dict:
      # 比赛保障逻辑：若无 key 或处于 Demo 模式，返回高质量预置题
      demo_quiz = {
          "question": f"关于【{concept_name}】的核心特征，下列描述最准确的是？",
          "options": [
              "它在系统调度中占有独立的虚拟地址空间与上下文",
              "它只能串行执行，无法被硬件中断触发状态流转",
              "它完全脱离硬件寄存器，纯在解释器用户态完成"
          ],
          "answer_index": 0,
          "explanation": f"正确！【{concept_name}】具有独立的资源分配与执行上下文特征。"
      }
      return ok(demo_quiz)
  ```
* 告诉前端同学这个接口的调用方式，双方进行第一次网络打通联调！
