## M-004 SessionManager（backend/middleware/session_manager.py）

包 v1 `servers.tutoring_mcp.session.SessionStore`（SessionContext 的 create/load/save 不重写），
另建 `session_summaries` 表承载 v2 新增元信息（摘要/已学概念/token/最后活跃/7 天 TTL）——
自建自管，不动 shared 13 表（同库第 15 表，cache_entries 之后）。

| 方法 | spec 03 场景 | 说明 |
|------|-------------|------|
| `list_sessions(user_id)` | 场景1 | 本人非 expired 会话 + 摘要元信息（LEFT JOIN session_summaries，缺则取 SessionRow.started_at 兜底）|
| `switch_session(user_id, sid)` | 场景2 | 加载目标 + 归属校验（非本人→SESSION_NOT_FOUND 不泄露）+ touch |
| `summarize(sid)` | 场景3 | **模板式摘要不依赖 LLM**："学过 X 概念（掌握 N）；薄弱 Y；下一步 Z"，落库 |
| `record_tokens`/`token_usage(sid)` | 场景4 | input/output/total 累计 |
| `cleanup_expired(now=)` | 场景5 | 超 7 天无活跃的非终态会话标记 expired，列表不再显示 |

接线：`app.state.sessions`（lifespan 建）+ `GET /api/tutoring/sessions?user_id=`（tutoring router）。

### 设计选择
- **摘要模板化而非 LLM**：死代理/无 key 时仍可生成摘要（鲁棒）；LLM 增强版留后续。
- **token 计数落 session_summaries 而非 SessionContext**：SessionContext schema 无 token 字段，不改 shared schema。
- 架构：SessionManager 在 middleware 层 import `servers.tutoring_mcp`（中间件包引擎合法，import-linter 4 kept）。
