## M-017 FileManager（backend/middleware/file_manager.py）

替换 v1 `shared.storage.FileStore`（按 corpus_id/kg_id 建目录，常是 UUID）为**人类可读结构**：

```
{root}/{user_id}/{subject_slug}/{kind}/...    kind ∈ corpora|knowledge_graphs|output|exports
```

- `subject_dir / dir_for / path_for / kg_version_dir(v{n}) / write_text / read_text / list_files / exists`
- **路径安全**：所有段过 `_safe`，拒绝 空 / `.` / `..` / `/` / `\` / 空字节——防目录穿越。
- 未知 kind → `INVALID_PATH`。
- 接线：`app.state.files = FileManager(config.files_root)`（默认 `data/`，DB 无关先建好）；新增 config `files_root`。
