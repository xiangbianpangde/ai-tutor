# BDD 规格：04 — 前端骨架（Electron + React）

> 对应功能点：#4 | 设计文档：[设计文档-前端桌面应用](../plan/design/设计文档-前端桌面应用.md)

## 功能 1：Electron 窗口启动

### 场景 1：双击启动
- 前置条件：已安装 AI-Tutor-2.0.0.exe
- 操作步骤：
  1. 双击桌面图标
- 预期结果：
  - 弹出启动画面（splash screen）
  - 3-10 秒后进入主界面（仪表盘）
  - 系统托盘出现 AI-Tutor 图标

### 场景 2：后端健康检查
- 前置条件：Electron 已 spawn Python 后端
- 操作步骤：
  1. Electron 轮询 `GET /api/knowledge/health`
- 预期结果：health check 通过后加载前端页面；超时 15 秒后显示"后端启动失败"

---

## 功能 2：5 页面路由

### 场景 1：侧边栏导航
- 前置条件：已进入主界面
- 操作步骤：
  1. 点击侧边栏"知识库"
  2. 点击"学习中心"
  3. 点击"复习中心"
  4. 点击"设置"
  5. 点击"仪表盘"
- 预期结果：每次点击切换对应页面，URL hash 对应变化

### 场景 2：仪表盘展示概览数据
- 前置条件：用户已有学习记录（掌握 17/30 概念）
- 操作步骤：
  1. 进入仪表盘
- 预期结果：显示 4 个指标卡（已掌握/学习中/今日学习时长/连续天数），数值正确

### 场景 3：设置页保存
- 前置条件：修改 LLM API key
- 操作步骤：
  1. 填入 `sk-xxx` → 点击"测试连接" → 提示"连接成功"
  2. 点击"保存"
- 预期结果：设置持久化到 `settings.json`，下次启动自动加载

---

## 功能 3：首次使用向导

### 场景 1：首次启动显示向导
- 前置条件：`settings.json` 不存在
- 操作步骤：
  1. 首次启动应用
- 预期结果：显示 3 步向导（配置 API → 学习偏好 → 开始使用）

### 场景 2：跳过 LLM 配置
- 前置条件：用户没有 API key
- 操作步骤：
  1. 在向导第 1 步点击"跳过"
- 预期结果：进入主界面，提示"基础功能可用，LLM 功能需配置 API key"

---

## 功能 4：WebSocket 通信

### 场景 1：实时教学通信
- 前置条件：已进入学习中心，WebSocket 已连接
- 操作步骤：
  1. 点击"下一题"
  2. 输入答案 → 提交
- 预期结果：延迟 < 200ms 收到反馈，无页面刷新

### 场景 2：WebSocket 断线重连
- 前置条件：WebSocket 连接已断开（后端重启）
- 操作步骤：
  1. 前端检测到断连
- 预期结果：自动重连（指数退避），重连成功后恢复教学状态
