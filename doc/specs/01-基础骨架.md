# BDD 规格：01 — 后端骨架（FastAPI 统一应用）

> 对应功能点：#1 | 设计文档：[设计文档-总体架构](../plan/design/设计文档-总体架构.md)

## 功能：FastAPI 应用骨架 + Python 后端统一入口

### 场景 1：后端启动成功
- 前置条件：Python 3.12+ 已安装，依赖已 `uv sync`
- 操作步骤：
  1. 执行 `uv run python -m backend.main`
  2. 等待控制台输出
- 预期结果：
  - 输出 `Uvicorn running on http://127.0.0.1:18501`
  - `GET /api/knowledge/health` 返回 `{"ok": true, "version": "2.0.0"}`

### 场景 2：共享模块导入无循环依赖
- 前置条件：`backend/core/` 已从 `shared/` 迁移
- 操作步骤：
  1. 运行 `uv run import-linter`
- 预期结果：无 forbidden 导入违规

### 场景 3：数据库自动初始化
- 前置条件：`data/tutor.db` 不存在
- 操作步骤：
  1. 启动后端
  2. `GET /api/knowledge/health`
- 预期结果：`data/tutor.db` 自动创建，14 张表全部存在

### 场景 4：异常场景 — 端口被占用
- 前置条件：端口 18501 已被其他进程占用
- 操作步骤：
  1. 启动后端
- 预期结果：报错 `Address already in use` 并退出，退出码非 0

### 场景 5：异常场景 — 数据库损坏
- 前置条件：`data/tutor.db` 文件损坏（非 SQLite 格式）
- 操作步骤：
  1. 启动后端，调任意 API
- 预期结果：返回 `{"ok": false, "error": {"code": "DATABASE_ERROR", "hint": "..."}}`
