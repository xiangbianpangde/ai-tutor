# BDD 规格：09 — 打包发布（Electron + Python 嵌入）

> 对应功能点：#9 | 设计文档：[设计文档-打包发布](../plan/design/设计文档-打包发布.md)

## 功能 1：Windows 安装包

### 场景 1：NSIS 安装程序
- 前置条件：构建产物 `AI-Tutor-Setup-2.0.0.exe`
- 操作步骤：
  1. 双击安装包
  2. 选择安装目录
  3. 等待安装完成
- 预期结果：
  - 桌面出现快捷方式
  - `%ProgramFiles%/AI-Tutor/` 包含 `AI-Tutor.exe` + `backend/ai-tutor-backend.exe`
  - 安装大小 ≤ 250MB

### 场景 2：首次启动
- 前置条件：安装完成
- 操作步骤：
  1. 双击桌面快捷方式
- 预期结果：
  - 弹出启动画面
  - Python 后端自动启动
  - 显示首次使用向导
  - `%APPDATA%/AI-Tutor/` 目录自动创建

### 场景 3：卸载
- 前置条件：AI-Tutor 已安装
- 操作步骤：
  1. 控制面板 → 卸载
- 预期结果：程序文件清除，用户数据保留（`%APPDATA%/AI-Tutor/` 不删，提示用户手动清理）

## 功能 2：离线核心功能

### 场景 1：无网络可用
- 前置条件：断网，已配置过 API key（但无网络也调不了 LLM）
- 操作步骤：
  1. 启动应用
  2. 查看已有 KG、复习计划
- 预期结果：BKT / 拓扑排序 / 遗忘曲线计算 / 复习调度 纯本地运行，不依赖网络

### 场景 2：LLM 功能降级提示
- 前置条件：无网络或无 API key
- 操作步骤：
  1. 尝试生成教学内容
- 预期结果：使用模板/启发式 fallback，提示"当前为离线模式，教学内容使用模板生成"

---

## 功能 3：自动更新

### 场景 1：检测新版本
- 前置条件：服务端有新版本 `2.0.1`
- 操作步骤：
  1. 启动应用
- 预期结果：弹窗"发现新版本 2.0.1，是否更新？"含 release notes

### 场景 2：增量更新
- 前置条件：用户确认更新
- 操作步骤：
  1. 下载增量包
  2. 安装
  3. 重启
- 预期结果：应用自动重启，版本号变为 2.0.1，用户数据不受影响

---

## 功能 4：macOS 兼容

### 场景 1：DMG 安装
- 前置条件：macOS 14+
- 操作步骤：
  1. 打开 `.dmg` → 拖入 Applications
- 预期结果：应用可正常启动，数据目录在 `~/Library/Application Support/AI-Tutor/`

### 场景 2：异常场景 — macOS 未公证
- 前置条件：应用未经过 Apple 公证
- 操作步骤：
  1. 首次打开
- 预期结果：macOS 提示"无法验证开发者"→ 用户手动允许后正常启动
