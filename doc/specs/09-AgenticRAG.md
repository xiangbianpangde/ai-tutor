# BDD 规格：07 — Agentic RAG + 缓存 + 监控

> 对应功能点：#7 | 设计文档：[设计文档-AgenticRAG](../plan/design/设计文档-AgenticRAG.md)

## 功能 1：Agentic RAG 多轮检索

### 场景 1：初检覆盖不足 → 自动深入检索
- 前置条件：用户查询"ACP大模型应用考试要求"
- 操作步骤：
  1. 发起 RAG 查询
  2. 系统初检返回 top 10 → LLM 评估覆盖率 45%
  3. 系统自动生成子查询 → 深入检索 → 追加 top 10
- 预期结果：最终返回 top 15 结果，LLM 评估覆盖率 ≥ 70%

### 场景 2：初检覆盖充足 → 不触发深入检索
- 前置条件：用户查询"导数定义"
- 操作步骤：
  1. 发起 RAG 查询
  2. 系统初检返回 top 10 → LLM 评估覆盖率 85%
- 预期结果：直接返回结果，不触发深入检索（节省 token）

### 场景 3：检索结果关联 KG 节点
- 前置条件：检索到"vLLM 部署优化"
- 操作步骤：
  1. 系统匹配 KG 概念
- 预期结果：返回结果中含 `kg_link: "acp:3.2:vllm_bushu"`，cosine 相似度 > 0.75

### 场景 4：异常场景 — 检索无结果
- 前置条件：查询完全不相关的内容
- 操作步骤：
  1. 查询 "XYZ123 不存在的内容"
- 预期结果：返回 `{"found": false, "suggestions": ["请尝试更具体的关键词"]}`

### 场景 5：迭代上限保护
- 前置条件：查询极其模糊，3 轮迭代后覆盖率仍 < 70%
- 操作步骤：
  1. 发起 RAG 查询
- 预期结果：最多 3 轮迭代后停止，返回当前最佳结果 + "部分结果可能需要人工补充"

## 功能 2：检索缓存

### 场景 1：相同查询缓存命中
- 前置条件：已检索过"机器学习监督学习"
- 操作步骤：
  1. 再次检索相同查询
- 预期结果：直接返回缓存结果，响应时间 < 50ms（vs 首次 2-5s）

### 场景 2：相似查询不命中
- 前置条件：已检索过"机器学习监督学习"
- 操作步骤：
  1. 检索"监督学习算法"（语义相近但字符串不同）
- 预期结果：不命中缓存（RAG 层不做语义去重），执行完整检索

## 功能 3：监控记录

### 场景 1：每次检索自动记录
- 前置条件：执行一次 RAG 检索
- 操作步骤：
  1. 检索完成
- 预期结果：自动记录 query / result_count / relevance_score / latency_ms / tokens_used 到 monitor_records

### 场景 2：质量下降告警
- 前置条件：连续 5 次检索 relevance_score < 0.4
- 操作步骤：
  1. 监控系统检测到异常
- 预期结果：前端弹出提醒"检索质量下降，建议更换搜索词或补充本地资料"
