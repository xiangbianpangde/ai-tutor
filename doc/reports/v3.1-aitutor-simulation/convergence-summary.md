## 三、6 棒链路收敛性分析

### 3.1 单调收敛性

```
CCI  0.988 → RCI  0.997 → CTI  0.97 → TDI  0.97 → ARI  0.99 → DDI  0.96 → FRI  0.995
                                                                                  ↑
                                                                            实际 0.9953
```

- **0.988 → 0.997**：RCI 比 CCI 高，因调研工具运行 5 次 + SOURCES 57 个 S/A 级来源
- **0.997 → 0.97**：CTI 略降，因业务规则 50 条（BR-001~050）覆盖面广，逻辑一致性比"覆盖性"略低
- **0.97 → 0.97**：TDI 与 CTI 持平（架构清晰度 ≈ 业务一致性）
- **0.97 → 0.99**：ARI 回升，AR 阶段 10/10 类齐全，AH-AITutor 自评 ARI=0.99
- **0.99 → 0.96**：DDI 略降，DD 阶段 17 模块全 7/7 通过但"4 舍 5 入保守下限"取 0.96
- **0.96 → 0.995**：FRI 回升，17 模块文件框架成熟度实际平均 0.9953

**所有 7 指数均 ≥ 0.85 门禁**，**均 ≥ 0.90 交付线**。

| 指标 | 数值 | 阶段 | 风险 |
