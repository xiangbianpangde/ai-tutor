## 发现并修复的真问题（R2）

- **问题**：导入失败时前端把后端原始 `TutorError: [KG_QUALITY_GATE_FAILED] 知识图谱质量门未通过`
  直接显示给用户——错误码 + 类名，非技术用户看不懂、不知道怎么办。
- **修复**（`LearnCenter.jsx`）：加 `humanize()` 把已知错误码映射成可操作的人话，并兜底剥掉
  `TutorError: [CODE]` 前缀。例：
  - 前：`TutorError: [KG_QUALITY_GATE_FAILED] 知识图谱质量门未通过`
  - 后：**「资料里没找到 # 标题，建不了科目。请用 # 标记章节（如「# 第一章」「## 小节」）后再试。」**
  覆盖 KG_QUALITY_GATE_FAILED / IMPORT_EMPTY / SUBJECT_NOT_FOUND / KG_NOT_BUILT / KG_NOT_FOUND。
- **复测**：重建前端 → 重跑 R2 → 报错变人话（截图 `clicktest-friendly-error.png`）；R5 正常路径不受影响。

## 结论

- 5 轮模拟点击（含多种"乱来"边界）**全部不崩溃**，应用始终可用、各页面健壮。
