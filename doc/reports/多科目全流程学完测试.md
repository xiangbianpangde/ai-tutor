# 多科目全流程"学完"测试报告（MiniMax 真判分）

> 用户要求：多个科目的全流程测试，**完全学完一个科目**（session status=completed），用 MiniMax API。
> 本报告记录实测结果 + 过程中发现并修复的真问题。

## 关键发现（修复前）

**无真 LLM 时，科目永远学不完。** 探针实测：StubLLM 下教学循环卡死在
`EXPLAIN→CHECK→(partial)→EXPLAIN`，40 步停在概念 1、mastery 0.16。根因：FIX-L 让回退启发式
**永不授 correct**（防 fluff 冒充掌握），但这也使 CHECK 永远过不去。

## 修复

1. **MiniMaxProvider**（真 LLM 判分）：OpenAI 兼容调 MiniMax-M3；剥 `<think>`/```json 围栏 +
   判分加 JSON-only 系统提示 + 单次重试，保证判分 JSON 可解析。
2. **LocalJudgeProvider**（无 key 基础模式）：确定性判分，可授 correct（克制 fluff），让无 key
   也能学完。
3. **编排器**：LLM 选择 注入 > MiniMax(有key) > 本地判分；动作增加 `interactive`/`completed` 元信息。
4. **前端学习中心**：展示步骤"继续→"、问答步骤"提交"、学完"🎉 本科目已学完"。
