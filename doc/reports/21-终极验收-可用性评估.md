## 一键导入建科目（已补，闭合零基础摩擦点）

发现第 6 步摩擦后**当场补齐**：
- 后端 `POST /api/knowledge/subjects/import`（采集→toc 建图→建 Subject，异步任务 + 进度轮询）。
- 前端学习中心"没有科目？导入资料新建"——粘贴 Markdown + 科目名 → 创建 → 进度条 → 科目自动
  就绪并回填 → 开始学习。
- **真 UI 端到端验证**（Playwright，空库起步）：概率论入门 markdown → 建图 **6 概念** →
  会话开起 → 教学内容（随机事件与概率）→ 作答得反馈。证据 `journey-import-learn.png` /
  `journey-import-exchange.png`。2 后端测试。

## 总体结论

- **可走通且零基础友好**：从双击安装 → 向导 → **导入自己的资料一键建科目** → 开始学习并
  完成问答，全程无需任何技术知识、无现成科目前提。已 Playwright 真驱动证实（非纸面）。
- **剩余只剩主观层**：让某个真人体验并打分"好不好用 / 教得透不透"——需真人，AI 无法替代。
- **签名**：未签名，SmartScreen 会提示；发布前加证书（成本项，非功能缺陷）。

> 技术链路 + 完整旅程（含零基础导入建科目）100% 通且真驱动验证。唯一不可由 AI 完成的是
