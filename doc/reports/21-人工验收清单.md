# #21 终极验收 · 人工验收清单（待真人执行）

> #21 的最后一环——"一个不懂代码的人，从安装走到学完第一课，并主观判断好不好用"——**只能由
> 一个真人执行**（AI 无法成为人类被试）。技术链路与完整旅程（含零基础导入建科目）已被 AI 真
> 驱动验证可走通（见 `21-终极验收-可用性评估.md` + journey-*.png），但"主观体验打分"需真人。
>
> 本清单给那个真人用：照着走，逐条勾，最后写一句"好不好用"。

## 准备
- [ ] 拿到安装包 `frontend/release/AI-Tutor Setup 2.0.0.exe`（139MB）
- [ ] 找一个**不懂编程**的人当被试（这是关键——别让写代码的人代劳）

## 安装（不应需要任何技术知识）
- [ ] 双击安装包（若 SmartScreen 提示"未知发布者"，点"更多信息→仍要运行"——发布前应加签名免此提示）
- [ ] 选安装目录 → 装好 → 桌面/开始菜单出现 AI-Tutor 图标
- [ ] 双击图标 → 应用窗口打开（首启动加载约数秒）

## 首次使用
- [ ] 看到"欢迎使用 AI-Tutor"向导
- [ ] 没有 API Key？点"跳过"（基础功能可用）
- [ ] 进入主界面，左下角"实时已连接"，仪表盘"子系统就绪 5/5"

## 从零建一个科目（零基础入口）
- [ ] 点左侧"学习中心"
- [ ] 点"没有科目？导入资料新建"
- [ ] 填科目名（如"概率论入门"）+ 粘贴一段带 # 标题的资料 → 点"创建科目"
- [ ] 等进度走完，科目 ID 自动填好

## 学第一课
- [ ] 点"开始学习" → 看到第一个教学内容（聊天气泡）
- [ ] 在输入框打字回答 → 提交 → 收到反馈（即时，<1 秒）
- [ ] 多答几轮，能感觉到在推进概念

## 主观判断（这是 AI 给不了的部分，请真人写）
- [ ] 整个过程**有没有卡住、看不懂的地方**？记下来：__________
- [ ] 不懂代码的人**能不能独立走完**（不用旁人教）？是 / 否
- [ ] **教得透不透**（学完真懂了一点东西吗）？1-5 分：____
- [ ] 一句话总体评价：__________

## 通过标准
被试**独立**从安装走到学完第一课，且主观评价"能用、学到了东西" → #21 通过。
如卡在某步，记录卡点 → 回工程修复（多数已知卡点见可用性评估文档）。
