## M-007 TaskManager（backend/middleware/task_manager.py）

线程池后台任务 + SQLite `tasks` 表状态持久化（自建自管，同库第 16 表）。

- `submit(kind, fn) -> task_id`：登记 pending 行 + 丢线程池，**立即返回**（不阻塞 HTTP）。
- `fn(reporter)`：任务体经 `ProgressReporter.update(progress, message)` 上报进度。
- `get(task_id)`：state(pending/running/succeeded/failed) + progress + message + result + error。
- `wait(task_id, timeout)`：join future（仅本进程任务，供测试/同步）。
- 失败记录 error 不上抛；result JSON 化（default=str）。
- **跨重启**：运行中任务的 future 不跨重启（运行中的进程无法续），但已落库的状态/结果重启后仍可查。

## build_kg 异步端点（backend/routers/knowledge.py）

- `POST /api/knowledge/subjects/{id}/graphs` body `{corpus_id, depth}` → submit 构建任务，**202 + task_id 立即返回**。
- `GET /api/tasks/{task_id}` → 轮询进度/结果（tasks router）。
- **build_runner 可注入**（`app.state.build_runner`）：默认 `default_build_runner` 复用 v1 builder
  （toc 免 LLM；concept/full 需 LLM 注入，后续波次）；**测试用假 runner，绝不真建图碰演示资产**。
- default_build_runner 与 v1 server.py 的差异：**不回写 subject.kg_id**（避免改既有 Subject 资产）。
