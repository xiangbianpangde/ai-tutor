## M-002 API 网关

- `backend/app.py` `create_app()`：FastAPI(title AI-Tutor, version 2.0.0) + CORS + lifespan + 四引擎 router。
- **统一信封**（`backend/responses.py`）：成功 `{ok:true,data}` / 失败 `{ok:false,error:{code,message,hint,retryable}}`；
  错误码→HTTP 状态映射（KG_NOT_FOUND 404 / KG_NOT_BUILT 409 / SESSION_EXPIRED 410 / RATE_LIMITED 429 …）。
- **三道异常处理器**：`TutorError`→对应状态信封 / `SQLAlchemyError`→DATABASE_ERROR 500 信封（BDD 01 场景5 形态）/
  兜底 `Exception`→INTERNAL_ERROR 500。
- **四引擎 router**（`backend/routers/`）：knowledge/tutoring/digest/sync 各挂 `/api/{engine}/health`,
  返回 `{ok:true,version:2.0.0,engine}`（BDD 01 场景1 精确匹配）；各模块是后续波次迁 endpoint 的家。
- ⚠️ **范围**：C1 只做网关 + health。#2 的 32 tool→REST/WS 完整迁移随各引擎在 C2-C4 落地（设计文档-后端API层 映射表已就位）。
