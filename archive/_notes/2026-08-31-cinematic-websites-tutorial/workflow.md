## 0. 如何使用本手册

- **从阶段 1 开始顺序执行**。每完成一段,把产物贴给 AI 验收,通过再进入下一段。
- **任何阶段失败,返回上一阶段**。不要跳过失败往前赶。
- **每段产物必须保留**。图片、视频文件、参考链接、Figma 截图、代码 commit,都要可回溯。
- **每个 if-then 决策都是硬约束**。满足 if 条件就必须执行 then,不要"看情况"。
- **每段都有"完成标准"**。未达标不算完成,即使视觉上看起来"差不多"也不行。

## 1. 七段式工作流

### 阶段 1 · 寻找参考

| 字段 | 值 |
|---|---|
| 目标 | 建立"审美坐标",把模糊形容词(高端/电影感/未来感)转成可检查的视觉约束 |
| 工具 | Pinterest(实验性)、SeeSaw、Land-book(成熟成品) |
| 输入 | 产品类型、目标情绪、目标用户 |
| 输出 | 3 类参考图(布局/装饰/配色),各 1-2 张 |
| 完成标准 | 至少 3 张不同维度的参考,每张能用一句话说明"为什么选它" |

**典型 prompt:**
```
我的产品是 [产品类型],目标用户 [用户画像],想要的氛围是 [情绪关键词]。
请给我 5 个高端官网案例链接,要求深色背景、首屏有强烈视觉冲击。
我需要从布局比例、装饰元素、配色三个维度各挑一张参考。
```

**反例:** 只找 1 张"我喜欢"的图作为全部参考。会导致 AI 把所有要求压缩到一种风格。

---

### 阶段 2 · 拆分参考

| 字段 | 值 |
|---|---|
| 目标 | 避免照搬;把不同参考分别用于布局、装饰、颜色 |
| 工具 | Pinterest(二次筛选)、Figma |
| 输入 | 阶段 1 的 3 类参考图 |
| 输出 | Figma 中的简易版式草图,标注"哪些元素来自哪张参考" |
| 完成标准 | 每个首屏元素都能回答"灵感来自哪张参考的哪个部分" |

**典型 prompt:**
```
我有这 3 张参考:
- 布局参考:[图 1] - 用于首屏整体比例和模块位置
- 装饰参考:[图 2] - 用于按钮、分割线、微动效
- 配色参考:[图 3] - 用于主色、辅色、对比色

请在 Figma 帮我建一个简易版式,标注每部分的灵感来源。
不要混用三张图的元素,每张图只贡献一类信息。
```

**反例:** 三张参考都给了同一类信息(比如都是布局参考),导致配色和动势仍然要 AI 自己猜。

---

### 阶段 3 · 生成视觉

| 字段 | 值 |
|---|---|
| 目标 | 得到适合网页首屏的定制背景图 |
| 工具 | ChatGPT Images(主力)、Higgsfield(备选) |
| 输入 | 阶段 2 的 Figma 草图 + 配色参考 + 装饰元素描述 |
| 输出 | 4-8 张候选背景图,16:9 或 21:9,主图 2-3 选 1 |
| 完成标准 | 候选图同时满足:构图留白可放 2 行 24px 白色标题、主体偏右/偏左(留出文案区)、光线方向明确 |

**典型 prompt(ChatGPT Images):**
```
生成 4 张 [产品类型] 的高端官网首屏背景图,16:9,深色基调。

构图要求:
- 主体偏画面右侧 1/3 处
- 画面下方 1/3 留出纯净空间用于放文字
- 光线从左上 45° 进来,主体有明显高光

视觉要求:
- 材质:[金属/玻璃/织物/...]
- 氛围:[电影感/未来感/极简奢华]
- 参考这张图的色调和质感:[贴配色参考图]

输出 4 个变体供我挑选,每个变体保持构图一致只调细节。
```

**反例:** 不指定留白区,生成的图主体居中,后面放文字时只能加黑色蒙版,失去原图的质感。

---

### 阶段 4 · 生成动效

| 字段 | 值 |
|---|---|
| 目标 | 把静态图转成可循环播放的视频背景 |
| 工具 | Seedance 2.0(主力,摄影机感运动)、Kling AI(备选,主体运动) |
| 输入 | 阶段 3 选定的 1 张主图 |
| 输出 | 5-10 秒循环视频,MP4,1080p 起步 |
| 完成标准 | 视频起止帧一致(可自然衔接),运动幅度不抢主体注意力,文件 < 5MB |

**典型 prompt(Seedance 2.0):**
```
基于这张静态图,生成一个 8 秒循环视频。

运动要求:
- 缓慢推近(camera push-in),不是主体变形
- 推近幅度不超过画面 10%
- 末帧与首帧一致(可无缝循环)
- 不要 zoom-in 超过 1.2x,否则失去原图构图

风格:摄影机缓慢移动,不要主体运动或变形。
```

**典型 prompt(Kling AI 备选):**
```
基于这张静态图,生成 8 秒循环视频。
运动方式:画面中 [主体] 缓慢 [运动描述,如"云雾飘动/光影流动"]。
不要改变构图和视角。
```

**反例:** 直接用 text-to-video 不给参考图。结果和阶段 3 的图脱节,变成两个不同的画面。

---

### 阶段 5 · 实现页面

| 字段 | 值 |
|---|---|
| 目标 | 先完成 Hero 段,再扩展到全页 |
| 工具 | ChatGPT Codex(写代码) + GPT-5.6 Sol(理解视觉意图) |
| 输入 | 阶段 4 的视频 + 阶段 2 的 Figma 草图 + 配色/字体规范 |
| 输出 | 完整可运行的 HTML/CSS/JS |
| 完成标准 | Hero 在桌面端 1920x1080、移动端 375x812 下均正确显示;视频循环无卡顿;文字可读 |

**典型 prompt:**
```
基于以下材料帮我实现一个高端官网 Hero 段:

视频背景:[mp4 链接或 base64]
配色:#0A0A0A 主背景, #D4A647 金色点缀, #F5F1E8 文字主色
字体:标题用 Playfair Display 700,副标题用 Inter 400
布局:左半部分标题+副标题+CTA 按钮,右半部分让视频完全显示

要求:
- 只实现 Hero 段,先不要做下面的内容
- 视频作为 background-video 循环播放,自动播放、静音
- 文字区域有从下到上的黑色渐变遮罩,确保可读性
- 移动端:视频铺满,文字区域下移,字号缩小 30%
```

**节奏:** Hero 验收通过再往下做。不要一上来就请求"生成整页"。

---

### 阶段 6 · 视觉融合

| 字段 | 值 |
|---|---|
| 目标 | 处理视频尺寸、背景冲突、混合效果,让各层融合成"一张图" |
| 工具 | CSS(主战场)、Figma(辅助) |
| 输入 | 阶段 5 的 Hero 页面 + 阶段 4 的视频 |
| 输出 | 视觉融合到位的 Hero + 完整页面 |
| 完成标准 | 视频/文字/按钮之间无明显边界;鼠标 hover 过渡自然;无突兀的硬边 |

**典型 prompt:**
```
当前 Hero 段存在以下视觉问题:
- [具体问题 1: 文字在视频亮区读不清]
- [具体问题 2: 按钮和视频背景颜色冲突]
- [具体问题 3: ...]

请只针对视觉融合改 CSS,不要改 HTML 结构。
```

**反例:** 文字读不清就直接换视频。视频不是为文字妥协的,应该是用 CSS 调和两者。

---

### 阶段 7 · 工程优化

| 字段 | 值 |
|---|---|
| 目标 | 解决倒放卡顿、响应式、移动端问题 |
| 工具 | Canvas API、requestVideoFrameCallback、Codex |
| 输入 | 阶段 6 完成的完整页面 |
| 输出 | 桌面/平板/移动三端流畅运行 |
| 完成标准 | 移动端 4G 网络下首屏 LCP < 2.5s;视频在低端 Android 设备不卡顿 |

**典型 prompt:**
```
在以下设备上验证这个页面:
- iPhone 13 (iOS 17, Safari)
- 小米 13 (Android 14, Chrome)
- iPad Air (Safari)
- 1920x1080 桌面 Chrome

请报告:
1. 每个设备上视频是否流畅循环(无掉帧)
2. 移动端是否有元素溢出或不可点击
3. LCP(最大内容绘制)大致时间

如果发现问题,只改 CSS / JS,不要改视觉。
```

## 2. 12 个关键技能(if-then 决策表)

> 每条都是硬规则。满足 if 条件就必须执行 then,不依赖"经验判断"。

| # | IF 条件 | THEN 执行 | 工具/技术 |
|---|---|---|---|
| 1 | 任何阶段开始前 | 先找 3 类参考(布局/装饰/配色),不直接进生成 | Pinterest + SeeSaw |
| 2 | 拿到一张"完美"参考图 | 拆成 3 个独立用途,不要全用 | Figma 标注 |
| 3 | 需要首屏背景图 | 明确指定留白区、主体位置、光线方向,4 个变体 | ChatGPT Images |
| 4 | ChatGPT Images 出图风格单一 | 切到 Higgsfield 跑第 2 套,交叉挑选 | Higgsfield |
| 5 | 已有静态图需要循环视频 | Seedance 2.0,摄影机感运动,末帧对齐首帧 | Seedance 2.0 |
| 6 | Seedance 效果不理想 | 切到 Kling AI,主体运动,保持构图 | Kling AI |
| 7 | 开始写页面 | 先做 Hero 段,验收通过再做全页 | Codex + GPT-5.6 Sol |
| 8 | 文字在视频背景上读不清 | CSS 渐变遮罩 + 文字白色 + 关键按钮描边 | CSS mix-blend-mode |
| 9 | 写代码前视觉没对齐 | Figma 量化版式:留白比例、字号、行高、模块间距 | Figma |
| 10 | 视频循环在某些浏览器卡顿 | Canvas 抽帧重绘,稳定帧率 | Canvas API |
| 11 | CSS 动效和视频帧漂移 | 用 rVFC 同步,精准对齐 | requestVideoFrameCallback |
| 12 | 桌面端完成 | 移动端单独在真机验一遍,只查 3 件事:视频不爆光、按钮可点、滚动不卡 | 真机测试 |

## 3. 工具决策矩阵

| 任务 | 首选 | 备选 | 切换触发 |
|---|---|---|---|
| 高端感图片(摄影感) | ChatGPT Images | Higgsfield | 出图风格单一,主选 4 张都是类似构图 |
| 抽象艺术感图片 | Higgsfield | ChatGPT Images | 主选结果"太实"不够艺术 |
| 摄影机感视频(背景) | Seedance 2.0 | Kling AI | 主体变形或运动过大 |
| 主体运动视频(展示) | Kling AI | Seedance 2.0 | 主体没有运动或动作僵硬 |
| 写代码 | Codex + GPT-5.6 Sol | Cursor + Claude | 单模型理解力不够 |
| 视觉对齐 | Figma | — | — |
| 寻找参考 | Pinterest(实验) | Land-book(成品) | 想要真实可上线案例时换 Land-book |

## 4. 反模式(明确不要做)

1. **不要一张参考图包打天下**——会同时污染布局、装饰、配色三个维度
2. **不要 text-to-video 不给参考**——和阶段 3 的图会脱节
3. **不要一上来就生成整页**——Hero 没验收就往下做,返工成本指数级
4. **不要在视频上直接加文字不调对比**——加 CSS 渐变/描边,不要换视频
5. **不要省掉 Figma 量化**——"我以为的"和"实际量出来的"差距会让代码反复回退
6. **不要桌面完成就上线**——移动端会暴露 80% 的"AI 模板感"问题
7. **不要用全屏 4K 视频**——移动端会爆带宽且烧电,Canvas 抽帧或降分辨率
8. **不要忽略循环起止帧**——视频跳一下,整个网站立刻显廉价

## 5. 端到端执行示例(以"AI 助听器产品页"为例)

```yaml
input:
  product: AI 助听器"听语"
  audience: 50+ 中老年用户
  mood: 温暖、可靠、不冷漠
  brand_color: 暖金 #D4A647
  reference_density: 高(已收集 12 张参考)

stage_1_寻找参考:
  action: 在 Pinterest 搜 "premium hearing aid website"
  result: 5 张候选
  拆分:
    - 布局参考:某医疗器械官网(简洁两栏)
    - 装饰参考:某高端音响品牌(暖光,圆形元素)
    - 配色参考:某助眠 App(米色 + 深棕)
  验收: ✅ 三类参考各 1 张,每张有理由

stage_2_拆分参考:
  tool: Figma
  deliverable: Hero 草图,标注:
    - 整体版式 ← 布局参考
    - 圆形装饰 + 暖光 ← 装饰参考
    - 米色背景 + 深棕文字 ← 配色参考
  验收: ✅ 每个元素标注来源

stage_3_生成视觉:
  tool: ChatGPT Images
  prompt_summary: "50+ 中老年用户的高端助听器,米色背景,主体偏左,暖光..."
  candidates: 4 张
  selection: 第 3 张(主体最清晰,留白最足)
  验收: ✅ 留白区可放 2 行文字,主体偏左,光线从右上

stage_4_生成动效:
  tool: Seedance 2.0
  input: 阶段 3 选定的图
  prompt_summary: "8 秒循环,缓慢推近 1.1x,末帧对齐首帧..."
  output: 8 秒 mp4,2.3MB
  验收: ✅ 循环无跳帧,文件 < 5MB

stage_5_实现页面:
  tool: Codex + GPT-5.6 Sol
  scope: 仅 Hero 段
  deliverable: index.html + style.css + main.js
  验收: ✅ 桌面 1920x1080 + 移动 375x812 均正常

stage_6_视觉融合:
  改_css: |
    - 文字区域加从下到上黑色渐变(opacity 0 → 0.6)
    - CTA 按钮加 1px 白色描边
    - 视频加 mix-blend-mode: multiply(微调)
  验收: ✅ 文字在任何视频帧下都可读

stage_7_工程优化:
  test_devices: [iPhone 13 Safari, 小米 13 Chrome, iPad Air, 桌面 Chrome]
  fixes:
    - 移动端视频降为 720p
    - 移动端去掉 hover 效果
    - 加 prefers-reduced-motion 检测
  验收: ✅ 4 设备均流畅,Lighthouse 性能分 > 85
```

## 6. 验收清单(每个阶段都过一遍)

- [ ] 阶段 1:3 张参考图,3 个维度,各 1 句话理由
- [ ] 阶段 2:Figma 草图,每个元素标注来源
- [ ] 阶段 3:候选图满足留白 + 主体位置 + 光线三条件
- [ ] 阶段 4:视频循环无跳帧,文件 < 5MB
- [ ] 阶段 5:Hero 在桌面 + 移动两个尺寸下显示正确
- [ ] 阶段 6:文字在所有视频帧下可读
- [ ] 阶段 7:4 设备测试通过,性能分 > 85
- [ ] 移动端单独检查:视频不爆光、按钮可点、滚动不卡
- [ ] 整套流程没有任何阶段"差不多"通过

## 7. 适用边界

本流程**不适用**于:
- 纯文字内容站(博客、文档)——视觉权重低,直接用 Tailwind/现成模板即可
- 数据密集型后台——清晰度优先于电影感
- 1-2 天快速上线的 MVP——用 Webflow / Framer 比走完整流程快 10 倍
- 已有品牌设计规范的公司站——以规范为准,这套流程只做"0→1"

**适用**于:
- 高端消费品(手表、珠宝、豪车、医美、家居)
- 品牌官网重设计
- 营销活动落地页
- 产品发布页
